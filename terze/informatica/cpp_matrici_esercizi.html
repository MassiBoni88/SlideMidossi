Esercizio 1 — Tabellone Voti

ESERCIZIO 1/2

Traccia

Una classe ha 4 studenti, ognuno con 5 voti. Memorizza i voti in una matrice int voti[4][5] letta da tastiera, poi:

  • Scrivi una funzione media(int v[], int n) che riceve un array (una riga) e restituisce la media come double.
  • Per ogni studente, stampa la sua media usando la funzione.
  • Stampa il numero dello studente con la media più alta.
  • Conta quanti voti complessivi sono insufficienti (< 6).
ⓘSuggerimento: in C++, m[i] è già un array — puoi passarlo come parametro int v[] alla funzione media.
⚠Argomenti coinvolti: matrici, cicli annidati, funzioni con array, if, contatori e ricerca del massimo.
// Traccia di soluzione
#include <iostream>
using namespace std;

const int S = 4;   // studenti
const int V = 5;   // voti

double media(int v[], int n) {
  int somma = 0;
  for (int i = 0; i < n; i++) {
    somma += v[i];
  }
  return (double)somma / n;
}

int main() {
  int voti[S][V];

  // 1) Lettura
  for (int i = 0; i < S; i++) {
    cout << "Studente " << i+1 << ":\n";
    for (int j = 0; j < V; j++) cin >> voti[i][j];
  }

  // 2) Media + studente migliore
  int migliore = 0;
  double maxMedia = media(voti[0], V);
  for (int i = 0; i < S; i++) {
    double mi = media(voti[i], V);
    cout << "Media stud. " << i+1
         << ": " << mi << "\n";
    if (mi > maxMedia) { maxMedia = mi; migliore = i; }
  }
  cout << "Migliore: studente " << migliore+1 << "\n";

  // 3) Insufficienti totali
  int ins = 0;
  for (int i = 0; i < S; i++)
    for (int j = 0; j < V; j++)
      if (voti[i][j] < 6) ins++;
  cout << "Insufficienze: " << ins;

  return 0;
}

Esercizio 2 — Matrice Magica?

ESERCIZIO 2/2

Traccia

Una matrice quadrata NxN è detta magica se la somma di ogni riga, di ogni colonna e delle due diagonali è la stessa.

Dato N = 3 e una matrice letta da tastiera, scrivi un programma che usa funzioni dedicate per verificare se la matrice è magica.

  • int sommaRiga(int m[][N], int r) — somma della riga r.
  • int sommaCol(int m[][N], int c) — somma della colonna c.
  • int sommaDiag(int m[][N], bool principale) — diagonale principale o secondaria.
  • In main: leggi la matrice, calcola le somme con un ciclo e stampa "Magica" oppure "Non magica".
✓Esempio di matrice magica 3x3 (somma = 15):
2 7 6 / 9 5 1 / 4 3 8
⚠Argomenti coinvolti: matrici, funzioni che ricevono matrici, cicli, condizioni logiche con && e bool.
// Traccia di soluzione
#include <iostream>
using namespace std;

const int N = 3;

int sommaRiga(int m[][N], int r) {
  int s = 0;
  for (int j = 0; j < N; j++) s += m[r][j];
  return s;
}

int sommaCol(int m[][N], int c) {
  int s = 0;
  for (int i = 0; i < N; i++) s += m[i][c];
  return s;
}

int sommaDiag(int m[][N], bool principale) {
  int s = 0;
  for (int i = 0; i < N; i++) {
    if (principale == true) {
      s += m[i][i];
    } else {
      s += m[i][N-1-i];
    }
  }
  return s;
}

int main() {
  int m[N][N];
  cout << "Inserisci 9 numeri:\n";
  for (int i = 0; i < N; i++)
    for (int j = 0; j < N; j++) cin >> m[i][j];

  int riferimento = sommaRiga(m, 0);
  bool magica = true;

  for (int i = 0; i < N; i++) {
    if (sommaRiga(m, i) != riferimento) magica = false;
    if (sommaCol(m, i)  != riferimento) magica = false;
  }
  if (sommaDiag(m, true)  != riferimento) magica = false;
  if (sommaDiag(m, false) != riferimento) magica = false;

  if (magica == true) cout << "Magica";
  else cout << "Non magica";
  return 0;
}
