Array — Dichiarazione e Accesso

SEZIONE 01

Cos'è un array?

Un array è una sequenza di elementi dello stesso tipo memorizzati in posizioni di memoria consecutive. Ogni elemento è accessibile tramite il suo indice, che parte da 0.

// Sintassi
tipo nome[dimensione];

// Dichiarazione e inizializzazione
int voti[5] = {8, 6, 9, 7, 5};

// Inizializzazione a zero
int contatori[10] = {0};

// Dimensione dedotta automaticamente
int numeri[] = {1, 2, 3};  // size = 3
voti[5] in memoria:
[0][1][2][3][4]

#include <iostream>
using namespace std;

int main() {
  int voti[5] = {8, 6, 9, 7, 5};

  // Accesso singolo
  cout << voti[0] << "\n";  // 8
  cout << voti[2] << "\n";  // 9

  // Modifica
  voti[1] = 10;

  // Scorrere con for
  for (int i = 0; i < 5; i++) {
    cout << voti[i] << " ";
  }
  // Output: 8 10 9 7 5

  // Calcolo della media
  int somma = 0;
  for (int v : voti) somma += v;
  cout << "Media: " << somma / 5.0 << "\n";

  return 0;
}
⚠ L'indice va da 0 a n-1. Accedere a voti[5] su un array di 5 elementi è un errore fuori dai limiti (undefined behavior).

Array Multidimensionali

SEZIONE 01

Array 2D — matrici

Un array bidimensionale si comporta come una tabella con righe e colonne. Si accede agli elementi con due indici: [riga][colonna].

// Dichiarazione: 3 righe, 4 colonne
int matrice[3][4];

// Inizializzazione
int m[2][3] = {
  {1, 2, 3},   // riga 0
  {4, 5, 6}    // riga 1
};

// Accesso: riga 1, colonna 2
cout << m[1][2] << "\n";  // 6
m[2][3] visualizzata:

[0]

2

#include <iostream>
using namespace std;

int main() {
  int m[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
  };

  // Stampa la matrice con for annidati
  for (int r = 0; r < 3; r++) {
    for (int c = 0; c < 3; c++) {
      cout << m[r][c] << "\t";
    }
    cout << "\n";
  }
  // Output:
  // 1  2  3
  // 4  5  6
  // 7  8  9

  return 0;
}
ⓘ Per conoscere la dimensione di un array in fase di compilazione usa sizeof(arr) / sizeof(arr[0]) che restituisce il numero di elementi.

Le strutture — struct

SEZIONE 02

Cos'è una struct?

Una struct raggruppa variabili di tipi diversi sotto un unico nome. Permette di modellare entità del mondo reale (uno studente, un prodotto, un punto nello spazio) come un unico oggetto.

// Definizione della struttura
struct Studente {
  string nome;
  int    eta;
  float  media;
};   // ← punto e virgola obbligatorio

// Dichiarazione di variabili
Studente s1;
Studente s2 = {"Luca", 17, 8.5};

// Accesso ai campi con il punto
s1.nome  = "Anna";
s1.eta   = 16;
s1.media = 7.2;

cout << s1.nome  << "\n";  // Anna
cout << s2.media << "\n";  // 8.5
#include <iostream>
#include <string>
using namespace std;

struct Studente {
  string nome;
  int    eta;
  float  media;
};

int main() {
  // Array di strutture
  Studente classe[3] = {
    {"Anna",  16, 7.2},
    {"Marco", 17, 8.5},
    {"Sara",  16, 9.1}
  };

  for (int i = 0; i < 3; i++) {
    cout << classe[i].nome  << " — media: "
         << classe[i].media << "\n";
  }

  return 0;
}
ⓘ La struct si definisce fuori dal main, prima di usarla. In C++ (a differenza del C) non serve il prefisso struct al momento della dichiarazione delle variabili.

Funzioni void senza parametri

SEZIONE 03

Perché usare le funzioni?

Una funzione è un blocco di codice con un nome, riutilizzabile più volte. Evita la duplicazione del codice e rende il programma più leggibile e facile da mantenere.

void — nessun valore di ritorno

Il tipo void indica che la funzione esegue operazioni ma non restituisce alcun valore al chiamante. Non ha return (o ha return; senza valore).

// Sintassi funzione void senza parametri
void nomeFunzione() {
  // corpo della funzione
}

// Chiamata
nomeFunzione();
#include <iostream>
using namespace std;

// Definizione PRIMA del main
void saluta() {
  cout << "Ciao! Benvenuto nel programma.\n";
}

void separatore() {
  cout << "-----------------------------\n";
}

int main() {
  saluta();       // chiamata
  separatore();   // chiamata
  saluta();       // riutilizzo

  return 0;
}
// Output:
// Ciao! Benvenuto nel programma.
// -----------------------------
// Ciao! Benvenuto nel programma.
ⓘ La funzione deve essere definita prima di essere chiamata, oppure bisogna dichiararne il prototipo in cima al file (vedremo nella slide successiva).

Funzioni con parametri e valore di ritorno

SEZIONE 03

Parametri

I parametri sono variabili che ricevono i valori passati al momento della chiamata. Si dichiarano tra parentesi con tipo e nome. I valori passati si chiamano argomenti.

// void CON parametri
void salutaPersona(string nome) {
  cout << "Ciao, " << nome << "!\n";
}

// Tipo di ritorno CON parametri
int somma(int a, int b) {
  return a + b;
}

float media(float x, float y) {
  return (x + y) / 2.0;
}

bool isPari(int n) {
  return (n % 2 == 0);
}
#include <iostream>
#include <string>
using namespace std;

void salutaPersona(string nome) {
  cout << "Ciao, " << nome << "!\n";
}

int somma(int a, int b) {
  return a + b;
}

bool isPari(int n) {
  return (n % 2 == 0);
}

int main() {
  salutaPersona("Mario"); // Ciao, Mario!

  int ris = somma(3, 7);
  cout << ris << "\n";       // 10

  cout << isPari(4) << "\n"; // 1 (true)
  cout << isPari(7) << "\n"; // 0 (false)

  return 0;
}
✓ return termina la funzione e restituisce il valore al chiamante. Il tipo del valore restituito deve corrispondere al tipo dichiarato nella firma della funzione.

Prototipo e riepilogo delle funzioni

SEZIONE 03

Il prototipo (dichiarazione anticipata)

Permette di definire le funzioni dopo il main, dichiarandone solo la firma in cima al file. Così il compilatore conosce la funzione prima di incontrarla nel codice.

#include <iostream>
using namespace std;

// Prototipi (dichiarazioni)
void saluta();
int  somma(int a, int b);

int main() {
  saluta();
  cout << somma(5, 3) << "\n";
  return 0;
}

// Definizioni DOPO il main
void saluta() {
  cout << "Ciao!\n";
}

int somma(int a, int b) {
  return a + b;
}

Librerie personalizzate — Panoramica

SEZIONE 04

Perché separare il codice?

Quando un programma cresce, mettere tutto in un unico file diventa difficile da gestire. Separare il codice in più file permette di:

  • Riutilizzare funzioni in più progetti
  • Dividere il lavoro in team
  • Compilare solo le parti modificate
  • Tenere il main.cpp pulito e leggibile

I tre file

📄 matematica.h

File header: contiene i prototipi delle funzioni e le definizioni di struct/costanti.

📄 matematica.cpp

File di implementazione: contiene il corpo di ogni funzione dichiarata nell'header.

📄 main.cpp

Punto di ingresso: include l'header e usa le funzioni senza conoscerne i dettagli interni.

Schema di dipendenze

matematica.h
↓ include
matematica.cpp
main.cpp
↓ compilati insieme
programma eseguibile
ⓘ Il file .h usa le include guard (#ifndef/#define/#endif) per evitare inclusioni multiple dello stesso header.

Il file header — matematica.h

SEZIONE 04

Struttura del file .h

Il file header dichiara tutto ciò che gli altri file possono usare: prototipi delle funzioni, strutture, costanti e tipi. Non contiene il corpo delle funzioni.

// matematica.h

// Include guard: evita inclusioni multiple
#ifndef MATEMATICA_H
#define MATEMATICA_H

// Costante
const double PI = 3.14159;

// Struttura
struct Punto {
  double x;
  double y;
};

// Prototipi delle funzioni
int    somma(int a, int b);
double areaCerchio(double raggio);
void   stampaPunto(Punto p);

#endif  // MATEMATICA_H

Come funziona l'include guard

Direttiva
Significato
#ifndef NOME_H
Se NOME_H non è ancora definita, procedi
#define NOME_H
Definisce NOME_H così le inclusioni successive vengono saltate
#endif
Chiude il blocco condizionale
ⓘ In alternativa alle include guard classiche, con i compilatori moderni si può usare #pragma once in cima al file: è più semplice e ha lo stesso effetto. 
// Alternativa moderna
#pragma once

// ... contenuto del file .h

Il file di implementazione — matematica.cpp

SEZIONE 04

Il .cpp implementa il .h

Il file di implementazione include il proprio header con "matematica.h" (virgolette, non parentesi angolari) e contiene il corpo completo di ogni funzione dichiarata nell'header.

// matematica.cpp
#include "matematica.h"
#include <iostream>
using namespace std;

int somma(int a, int b) {
  return a + b;
}

double areaCerchio(double raggio) {
  return PI * raggio * raggio;
}

void stampaPunto(Punto p) {
  cout << "(" << p.x << ", "
            << p.y << ")\n";
}

Differenza tra < > e " "

Sintassi
Dove cerca il file
Usato per
#include <file>

Librerie standard
#include "file"

Librerie personali
✓ Convenzione: usa < > per header di sistema (<iostream>, <string>) e " " per i tuoi file personali ("matematica.h").

Il main.cpp e la compilazione

SEZIONE 04

main.cpp — usa la libreria

Il main include solo l'header e usa le funzioni. Non ha bisogno di conoscere come sono implementate: è il principio di astrazione.

// main.cpp
#include <iostream>
#include "matematica.h"  // ← libreria nostra
using namespace std;

int main() {
  // Usa la funzione dalla libreria
  cout << somma(4, 7) << "\n";       // 11

  cout << areaCerchio(5.0) << "\n"; // 78.5397

  Punto p = {3.0, 4.0};
  stampaPunto(p);                    // (3, 4)

  return 0;
}

Struttura del progetto

progetto/
  ├ matematica.h   ← dichiarazioni
  ├ matematica.cpp  ← implementazioni
  └ main.cpp       ← programma principale

Compilazione da terminale (g++)

# Compila tutti i file insieme
g++ main.cpp matematica.cpp -o programma

# Oppure in due passi (file oggetto)
g++ -c matematica.cpp -o matematica.o
g++ -c main.cpp       -o main.o
g++ main.o matematica.o -o programma

# Esegui
./programma
ⓘ Con IDE come Visual Studio o Code::Blocks, basta aggiungere tutti i file al progetto: la compilazione multipla viene gestita automaticamente.
