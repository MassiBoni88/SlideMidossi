Che cos'è un algoritmo?

SEZIONE 01

Definizione

Un algoritmo è una sequenza finita e ordinata di passi (istruzioni) non ambigui che, partendo da alcuni dati iniziali (input), permette di risolvere un problema producendo un risultato (output) in un tempo finito.

ⓘLa parola deriva da al-Khwārizmī, matematico persiano del IX secolo: i suoi metodi di calcolo presero il nome di "algoritmi".
✓Un algoritmo è indipendente dal linguaggio di programmazione: prima si pensa la soluzione, poi la si traduce in C++, Python, Java…

Algoritmi di tutti i giorni

Anche senza un computer usiamo algoritmi continuamente. Sono "ricette" di passi da seguire in ordine:

  • La ricetta di una torta
  • Le istruzioni per montare un mobile
  • Le indicazioni stradali per arrivare a scuola
  • I passi per fare una divisione in colonna
⚠Una ricetta poco chiara ("aggiungi un po' di sale") non è un buon algoritmo: i passi devono essere precisi e non lasciare dubbi.

Le proprietà di un algoritmo

SEZIONE 01
✓

Finitezza

È composto da un numero finito di passi e deve terminare, non può durare all'infinito.

✓

Non ambiguità

Ogni passo ha un solo significato possibile: chi lo esegue non deve interpretare.

✓

Eseguibilità

Ogni operazione deve essere realmente realizzabile con le risorse a disposizione.

✓

Determinismo

Con gli stessi dati di input produce sempre lo stesso risultato.

✓

Input / Output

Riceve zero o più dati in ingresso e produce almeno un risultato.

✓

Generalità

Risolve una classe di problemi (es. tutte le medie) e non un singolo caso.

Dal problema alla soluzione

SEZIONE 02

Le fasi della risoluzione

Prima di scrivere anche solo una riga di codice, un programmatore segue sempre questo percorso:

1

Analisi

Capisco il problema: cosa mi viene dato e cosa devo ottenere?

2

Dati

Individuo i dati di input e di output e come si chiamano.

3

Algoritmo

Progetto i passi della soluzione (pseudocodice o flowchart).

4

Codifica

Traduco l'algoritmo nel linguaggio scelto (es. C++).

5

Test

Provo il programma con esempi e correggo gli errori.

I dati: variabili e costanti

  • Variabile: un contenitore con un nome il cui valore può cambiare durante l'esecuzione (es. somma).
  • Costante: un valore che non cambia mai (es. PI = 3.14).

I tre tipi di dato

  • Input → dati che ricevo dall'esterno (tastiera).
  • Lavoro → dati temporanei usati durante i calcoli.
  • Output → risultati che mostro all'utente.

Come si rappresenta un algoritmo

SEZIONE 03

Linguaggio naturale

Descrizione a parole, come parliamo. Semplice ma può essere ambiguo e poco preciso.

Chiedo i due numeri,
li sommo, divido per
due e mostro il
risultato a schermo.

Pseudocodice

Linguaggio semi-formale: a metà tra l'italiano e il codice. Preciso ma indipendente dal linguaggio.

INIZIO
  LEGGI a, b
  m ← (a + b) / 2
  SCRIVI m
FINE

Diagramma di flusso

Rappresentazione grafica con simboli e frecce. Molto chiaro per visualizzare il percorso.

INIZIO
Leggi a, b
m ← (a+b)/2
Scrivi m
FINE

I simboli del diagramma di flusso

SEZIONE 03
INIZIO / FINE
Terminale (ovale)
Segna l'inizio e la fine dell'algoritmo.
Leggi / Scrivi
Input / Output
Lettura dati (tastiera) o stampa dei risultati.
x ← y + 1
Elaborazione (rettangolo)
Un calcolo o un'assegnazione a una variabile.
a > b ?
Decisione (rombo)
Una domanda con risposta Vero o Falso: il flusso si divide in due.
Freccia di flusso
Indica l'ordine in cui si seguono i blocchi.
ⓘOgni blocco ha una sola freccia in uscita… tranne il rombo, che ne ha due: una per il "Vero" e una per il "Falso".

Esempio 1 — Media di due numeri

SEQUENZA

Il problema

Dati due numeri, calcolarne la media aritmetica. È un algoritmo a sola sequenza: nessuna scelta, nessuna ripetizione.

INIZIO
  LEGGI a
  LEGGI b
  media ← (a + b) / 2
  SCRIVI media
FINE
ⓘIl simbolo ← significa "assegna": il valore a destra viene messo nella variabile a sinistra.

Il diagramma di flusso

INIZIO
Leggi a, b
media ← (a + b) / 2
Scrivi media
FINE
✓Con a = 6 e b = 8 → media = 7. Stesso input, stesso output: l'algoritmo è deterministico.

Esempio 2 — Il maggiore tra due numeri

SELEZIONE

Il problema

Dati due numeri, stabilire e mostrare quale è il più grande. Serve una selezione: una domanda con due possibili strade.

INIZIO
  LEGGI a, b
  SE a > b ALLORA
    SCRIVI a
  ALTRIMENTI
    SCRIVI b
  FINE SE
FINE
ⓘLa condizione a > b è un'espressione booleana: può valere solo Vero o Falso.

Il diagramma di flusso

INIZIO
Leggi a, b
a > b ?
VERO
Scrivi a
FALSO
Scrivi b
FINE

Esempio 3 — Somma dei primi N numeri

ITERAZIONE

Il problema

Sommare tutti i numeri da 1 a N (es. 1+2+3+4). Non sappiamo quante somme servono finché non leggiamo N: serve un'iterazione.

INIZIO
  LEGGI N
  somma ← 0
  i ← 1
  MENTRE i ≤ N RIPETI
    somma ← somma + i
    i ← i + 1
  FINE MENTRE
  SCRIVI somma
FINE
INIZIO
Leggi N
somma ← 0 ; i ← 1
↻ FINCHÉ i ≤ N
somma ← somma + i
i ← i + 1
Scrivi somma
FINE
✓Con N = 4: i passi danno 0→1→3→6→10. Risultato finale: 10.

Dall'algoritmo al C++

CONCLUSIONE

Tabella di traduzione

Quando inizierai a programmare, ogni passo dello pseudocodice avrà il suo corrispondente in C++:

Pseudocodice
In C++
LEGGI x
cin >> x;
SCRIVI x
cout << x;
x ← 5
x = 5;
SE … ALLORA
if (…) { … }
MENTRE … RIPETI
while (…) { … }

Errori da evitare

  • Passi ambigui o incompleti
  • Dimenticare di aggiornare la variabile in un ciclo → loop infinito
  • Non definire bene input e output
  • Saltare la fase di test
✓Regola d'oro: prima pensa l'algoritmo, poi scrivi il codice. Un buon algoritmo rende la programmazione facile.
