L'istruzione if

SEZIONE 01

Come funziona

Il blocco tra le graffe viene eseguito solo se la condizione è true. Con else if si possono gestire più casi in cascata.

// Sintassi base
if (condizione) {
  // eseguito se true
}

// if ... else
if (condizione) {
  // ramo vero
} else {
  // ramo falso
}

// if ... else if ... else
if (voto >= 9) {
  cout << "Ottimo\n";
} else if (voto >= 6) {
  cout << "Sufficiente\n";
} else {
  cout << "Insufficiente\n";
}
#include <iostream>
using namespace std;

int main() {
  int eta = 20;

  if (eta >= 18) {
    cout << "Maggiorenne\n";
  } else {
    cout << "Minorenne\n";
  }

  int voto = 7;
  if (voto >= 9) {
    cout << "Ottimo\n";
  } else if (voto >= 6) {
    cout << "Sufficiente\n";
  } else {
    cout << "Insufficiente\n";
  }

  return 0;
}
ⓘCon una sola istruzione le graffe sono opzionali, ma è buona pratica includerle sempre.

if annidati e operatore ternario

SEZIONE 01

if annidati

Un if può contenerne un altro al suo interno. Ogni blocco ha la propria condizione indipendente.

int x = 15;

if (x > 0) {
  cout << "Positivo\n";

  if (x % 2 == 0) {
    cout << "e pari\n";
  } else {
    cout << "e dispari\n";
  }
} else {
  cout << "Non positivo\n";
}
// Output: Positivo  e dispari

Operatore ternario ? :

Forma compatta di if-else su una riga. Restituisce uno dei due valori in base alla condizione.

// Sintassi
variabile = (condizione) ? val_vero : val_falso;

// Esempio
int a = 10, b = 20;

// Con if-else
int max;
if (a > b) max = a;
else        max = b;

// Con ternario (equivalente)
int max2 = (a > b) ? a : b;

cout << max2 << "\n";  // 20
ⓘUsa il ternario solo per espressioni semplici. Per logica complessa preferisci if-else.

L'istruzione switch

SEZIONE 02

Quando usarlo

Lo switch confronta una variabile con valori costanti (case). È più leggibile di una lunga catena di else if quando si confronta la stessa variabile con valori discreti.

// Sintassi
switch (variabile) {
  case valore1:
    // codice
    break;
  case valore2:
    // codice
    break;
  default:
    // se nessun case corrisponde
}
⚠Attenzione al fall-through: senza break, l'esecuzione continua nel case successivo.
#include <iostream>
using namespace std;

int main() {
  int giorno = 3;

  switch (giorno) {
    case 1:
      cout << "Lunedì\n";   break;
    case 2:
      cout << "Martedì\n";   break;
    case 3:
      cout << "Mercoledì\n";  break;
    case 6:
    case 7:
      cout << "Weekend!\n";   break;
    default:
      cout << "Altro giorno\n";
  }
  // Output: Mercoledì

  return 0;
}
ⓘCase 6 e 7 senza break tra loro: è il fall-through intenzionale per gestire più valori con lo stesso blocco.

Il ciclo while

SEZIONE 03

Pre-test: condizione prima del corpo

Il ciclo while valuta la condizione prima di eseguire il corpo. Se la condizione è subito false, il corpo non viene mai eseguito.

// Sintassi
while (condizione) {
  // corpo
  // aggiorna la variabile!
}

// Conta da 1 a 5
int i = 1;
while (i <= 5) {
  cout << i << " ";
  i++;
}
// Output: 1 2 3 4 5
⚠Loop infinito: se dimentichi di aggiornare la variabile di controllo, la condizione rimane sempre true e il programma si blocca.
#include <iostream>
using namespace std;

int main() {
  // Somma finché input != 0
  int n, somma = 0;

  cout << "Inserisci numeri (0 per finire):\n";
  cin >> n;

  while (n != 0) {
    somma += n;
    cin >> n;
  }

  cout << "Somma: " << somma << "\n";

  return 0;
}
✓Il while è ideale quando la condizione di uscita dipende da un input esterno o da un evento imprevedibile.

Il ciclo do-while

SEZIONE 03

Post-test: corpo eseguito almeno una volta

Il ciclo do-while esegue il corpo prima di valutare la condizione, garantendo almeno una esecuzione.

// Sintassi
do {
  // corpo eseguito almeno una volta
} while (condizione);  // ← punto e virgola!

// Confronto: x = 10, condizione x < 5
// while     → 0 iterazioni (mai entra)
// do-while  → 1 iterazione (esegue una volta)

int x = 10;
do {
  cout << x;   // stampa 10
} while (x < 5);
#include <iostream>
using namespace std;

int main() {
  // Validazione input
  int voto;

  do {
    cout << "Inserisci voto (0-10): ";
    cin >> voto;

    if (voto < 0 || voto > 10)
      cout << "Voto non valido!\n";

  } while (voto < 0 || voto > 10);

  cout << "Voto accettato: " << voto << "\n";

  return 0;
}
ⓘIl do-while è la scelta naturale per la validazione dell'input: devi chiedere il valore almeno una volta, poi ripetere solo se non è valido.

Il ciclo for

SEZIONE 04

Ciclo a contatore

Il for è ideale quando il numero di iterazioni è noto. Riunisce inizializzazione, condizione e aggiornamento in una sola riga.

// Sintassi
for (inizio; condizione; aggiornamento) {
  // corpo
}

// Conta avanti: 1 2 3 4 5
for (int i = 1; i <= 5; i++) {
  cout << i << " ";
}

// Conta indietro: 5 4 3 2 1
for (int i = 5; i >= 1; i--) {
  cout << i << " ";
}
#include <iostream>
using namespace std;

int main() {
  // Tavola del 7
  for (int i = 1; i <= 10; i++) {
    cout << "7 x " << i << " = "
         << 7*i << "\n";
  }

  // For annidati: matrice 3x3
  for (int r = 1; r <= 3; r++) {
    for (int c = 1; c <= 3; c++) {
      cout << r*c << "\t";
    }
    cout << "\n";
  }

  return 0;
}
ⓘLa variabile i dichiarata nel for esiste solo all'interno del ciclo (scope locale).

for range-based e confronto cicli

SEZIONE 04

for range-based (C++11)

Permette di iterare su ogni elemento di una collezione (array, stringa, vettore) senza gestire manualmente l'indice.

#include <iostream>
#include <string>
using namespace std;

int main() {
  int numeri[] = {10, 20, 30, 40};

  for (int n : numeri) {
    cout << n << " ";
  }
  // Output: 10 20 30 40

  string parola = "Ciao";
  for (char c : parola) {
    cout << c << "-";
  }
  // Output: C-i-a-o-

  return 0;
}

Quando usare quale ciclo?

Ciclo
Usalo quando…
for
conosci il numero esatto di iterazioni

devi scorrere tutti gli elementi di una collezione

✓Il for range-based è più sicuro e leggibile del classico for con indice quando non ti serve il numero dell'iterazione.

break e continue

SEZIONE 05

break — interrompe il ciclo

break termina immediatamente il ciclo (o lo switch) più interno e passa all'istruzione successiva.

int main() {
  // Esce quando trova 5
  for (int i = 1; i <= 10; i++) {
    if (i == 5) break;
    cout << i << " ";
  }
  // Output: 1 2 3 4

  // Cerca il primo pari
  int n = 1;
  while (true) {
    if (n % 2 == 0) break;
    n++;
  }
  cout << "Primo pari: " << n << "\n";
  // Output: Primo pari: 2

  return 0;
}

continue — salta all'iterazione successiva

continue salta il resto del corpo per l'iterazione corrente e passa direttamente alla prossima.

int main() {
  // Stampa solo i dispari
  for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;
    cout << i << " ";
  }
  // Output: 1 3 5 7 9

  return 0;
}
