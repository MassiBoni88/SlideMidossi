⚠Divisione intera: se entrambi gli operandi sono int, il risultato è intero (10/3 = 3). Per ottenere un decimale usa double.
ⓘPrecedenza: *, / e % hanno priorità su + e -. Usa le parentesi per forzare l'ordine di valutazione.
#include <iostream>
using namespace std;

int main() {
  int a = 10, b = 3;

  cout << a + b << "\n";  // 13
  cout << a - b << "\n";  // 7
  cout << a * b << "\n";  // 30
  cout << a / b << "\n";  // 3
  cout << a % b << "\n";  // 1

  a++;
  cout << a << "\n";      // 11
  b--;
  cout << b << "\n";      // 2

  return 0;
}

⚠Errore comune: non confondere == (confronto) con = (assegnazione). Scrivere if (x = 5) assegna 5 a x invece di confrontare!
#include <iostream>
using namespace std;

int main() {
  int x = 5;

  cout << (x == 5) << "\n";  // 1 (true)
  cout << (x != 3) << "\n";  // 1 (true)
  cout << (x >  3) << "\n";  // 1 (true)
  cout << (x <  3) << "\n";  // 0 (false)
  cout << (x >= 5) << "\n";  // 1 (true)
  cout << (x <= 4) << "\n";  // 0 (false)

  return 0;
}

#include <iostream>
using namespace std;

int main() {
  int x = 5;

  // AND
  if (x > 3 && x < 10) {
    cout << "x è tra 3 e 10\n";
  }
  // OR
  if (x == 5 || x == 7) {
    cout << "x è 5 oppure 7\n";
  }
  // NOT
  if (!(x == 3)) {
    cout << "x NON è 3\n";
  }

  return 0;
}
ⓘShort-circuit: con &&, se il primo operando è false, il secondo non viene valutato. Con ||, se il primo è true, il secondo viene saltato.

Stringhe in C++

SEZIONE 04

std::string

In C++ le stringhe si gestiscono con il tipo string, incluso in <string>. Una stringa è una sequenza di caratteri racchiusi tra virgolette doppie.

#include <iostream>
#include <string>
using namespace std;

int main() {
  string nome = "Mario";
  string cognome = "Rossi";

  cout << nome    << "\n";  // Mario
  cout << cognome << "\n";  // Rossi

  return 0;
}
ⓘIncludi sempre #include <string> quando usi std::string.

Input di stringhe

Con cin si legge una parola sola. Per leggere una riga intera con spazi si usa getline().

#include <iostream>
#include <string>
using namespace std;

int main() {
  string parola, frase;

  // Legge una sola parola
  cin >> parola;

  // Legge una riga intera
  cin.ignore();
  getline(cin, frase);

  cout << parola << "\n";
  cout << frase  << "\n";

  return 0;
}

Concatenazione e Lunghezza

SEZIONE 04

Concatenazione

L'operatore + unisce due stringhe. Si può usare anche += per aggiungere in coda. Il metodo append() è equivalente.

int main() {
  string nome    = "Mario";
  string cognome = "Rossi";

  string completo = nome + " " + cognome;
  cout << completo << "\n"; // Mario Rossi

  nome += " Bianchi";
  cout << nome << "\n";    // Mario Bianchi

  string s = "Ciao";
  s.append(" Mondo");
  cout << s << "\n";       // Ciao Mondo

  return 0;
}

Lunghezza della stringa

Il metodo length() (o size()) restituisce il numero di caratteri della stringa.

int main() {
  string testo = "Programmazione";

  cout << testo.length() << "\n"; // 14
  cout << testo.size()   << "\n"; // 14

  if (testo.length() > 10) {
    cout << "Stringa lunga\n";
  }

  return 0;
}
ⓘlength() e size() sono identici per std::string. Entrambi restituiscono un size_t (intero senza segno).

Accesso ai Caratteri

SEZIONE 04

Indici e operatore [ ]

Ogni carattere è accessibile tramite il suo indice, che parte da 0. Il metodo at() è simile ma verifica i limiti lanciando un'eccezione.

"Ciao"  →  C=0  i=1  a=2  o=3

int main() {
  string s = "Ciao";

  cout << s[0]      << "\n";  // C
  cout << s[1]      << "\n";  // i
  cout << s.at(2)   << "\n";  // a

  // Modifica di un carattere
  s[0] = 'M';
  cout << s << "\n";           // Miao

  return 0;
}
⚠Attenzione: [] fuori dai limiti causa comportamento non definito. Usa at() per un controllo sicuro.

Variabili Booleane

SEZIONE 05

Il tipo bool

Il tipo bool può contenere solo due valori: true (equivale a 1) oppure false (equivale a 0). È il tipo restituito dagli operatori di comparazione e logici.

Valore
Rappresentazione numerica
Output cout
true
1
1
false
0
0
ⓘPer stampare true/false invece di 1/0 usa cout << boolalpha prima della stampa.
#include <iostream>
using namespace std;

int main() {
  bool piove = true;
  bool sole  = false;

  cout << piove << "\n";  // 1
  cout << sole  << "\n";  // 0

  cout << boolalpha;
  cout << piove << "\n";  // true
  cout << sole  << "\n";  // false

  int x = 7;
  bool grande = (x > 5);
  cout << grande << "\n"; // true

  if (piove) {
    cout << "Prendi l'ombrello!\n";
  }

  return 0;
}
✓Qualsiasi valore numerico diverso da 0 è true. Solo 0 è false.
