Cos'è una Matrice?

SEZIONE 01

Definizione

Una matrice è un array bidimensionale: una struttura dati che organizza i valori in righe e colonne, come una tabella. Tutti gli elementi devono essere dello stesso tipo.

Sintassi della dichiarazione

tipo nome[RIGHE][COLONNE];

// Esempi
int    voti[3][4];     // 3x4 = 12 interi
double mat[2][2];      // 2x2 = 4 double
char   griglia[5][5]; // 5x5 caratteri
⚠Dimensioni fisse: il numero di righe e colonne deve essere noto al momento della compilazione e non può cambiare durante l'esecuzione.

Inizializzazione

SEZIONE 02

Inizializzazione esplicita

Si possono assegnare i valori direttamente alla dichiarazione, usando le parentesi graffe. Ogni gruppo interno corrisponde a una riga della matrice.

Inizializzazione a zero

Per riempire tutta la matrice di zeri basta usare le graffe vuote {} oppure {0}.

✓Se ometti dei valori, le celle restanti vengono automaticamente messe a 0. Comodo per matrici grandi inizializzate a zero.
⚠Errore comune: dimenticare le graffe interne. int m[2][3] = {1,2,3,4,5,6}; funziona ma è meno chiaro di {{1,2,3},{4,5,6}}.
#include <iostream>
using namespace std;

int main() {
  // Inizializzazione esplicita 2x3
  int m[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
  };

  // Tutti zeri (3x3)
  int zeri[3][3] = {};

  // Solo prime celle, resto 0
  int p[2][2] = {{7}};
  // p = { {7,0}, {0,0} }

  cout << m[0][0] << "\n"; // 1
  cout << m[1][2] << "\n"; // 6
  cout << p[1][1] << "\n"; // 0

  return 0;
}

Accesso agli Elementi

SEZIONE 02

Sintassi m[riga][colonna]

Per leggere o modificare un elemento si usano due indici: il primo indica la riga, il secondo la colonna. Gli indici partono da 0.

c0
c1
c2
r0
10
20
30
r1
40
50
60
ⓘm[0][1] → 20 (cella verde) · m[1][2] → 60 (cella blu)
⚠Attenzione: accedere fuori dai limiti (es. m[2][0] in una 2x3) causa comportamento non definito. Il C++ non controlla per te!
#include <iostream>
using namespace std;

int main() {
  int m[2][3] = {
    {10, 20, 30},
    {40, 50, 60}
  };

  // Lettura
  cout << m[0][1] << "\n"; // 20
  cout << m[1][2] << "\n"; // 60

  // Modifica
  m[0][0] = 99;
  cout << m[0][0] << "\n"; // 99

  // Operazioni aritmetiche
  m[1][1] += 5;
  cout << m[1][1] << "\n"; // 55

  return 0;
}

Scorrere una Matrice con i Cicli

SEZIONE 03

Due cicli for annidati

Per scorrere tutta la matrice servono due cicli: quello esterno gestisce le righe, quello interno le colonne. È il pattern più importante da imparare!

// Stampa una matrice 3x4
const int R = 3, C = 4;
int m[R][C] = {
  {1,2,3,4}, {5,6,7,8}, {9,8,7,6}
};

for (int i = 0; i < R; i++) {
  for (int j = 0; j < C; j++) {
    cout << m[i][j] << "\t";
  }
  cout << "\n"; // a capo a fine riga
}
ⓘUsa const int per definire le dimensioni: il codice resta leggibile e modificabile da un solo punto.

Lettura da tastiera

Lo stesso schema serve per leggere una matrice riempiendola con cin.

#include <iostream>
using namespace std;

int main() {
  const int R = 2, C = 3;
  int m[R][C];

  cout << "Inserisci 6 numeri:\n";
  for (int i = 0; i < R; i++) {
    for (int j = 0; j < C; j++) {
      cout << "m[" << i << "]["
           << j << "] = ";
      cin >> m[i][j];
    }
  }

  cout << "Matrice inserita!\n";
  return 0;
}
ⓘConvenzione: le variabili i e j indicano riga e colonna. r e c sono altrettanto comuni.

Operazioni Comuni

SEZIONE 03

Somma di tutti gli elementi

int somma = 0;
for (int i = 0; i < R; i++) {
  for (int j = 0; j < C; j++) {
    somma += m[i][j];
  }
}
cout << "Totale: " << somma;

Massimo della matrice

int max = m[0][0];
for (int i = 0; i < R; i++) {
  for (int j = 0; j < C; j++) {
    if (m[i][j] > max) {
      max = m[i][j];
    }
  }
}
cout << "Massimo: " << max;

Somma di una singola riga

// Somma elementi riga r
int r = 1;
int somRiga = 0;
for (int j = 0; j < C; j++) {
  somRiga += m[r][j];
}
cout << "Riga " << r
     << ": " << somRiga;

Conta valori che soddisfano una condizione

// Conta i pari
int conta = 0;
for (int i = 0; i < R; i++) {
  for (int j = 0; j < C; j++) {
    if (m[i][j] % 2 == 0) conta++;
  }
}
cout << "Pari: " << conta;

Matrici come Parametri di Funzione

SEZIONE 04

Passare una matrice

Per passare una matrice a una funzione bisogna specificare il numero di colonne nel parametro. Il numero di righe può essere passato come parametro separato.

Sintassi
Significato
int m[][3]
Matrice di interi con 3 colonne
int m[2][3]
Esplicitamente 2x3 (le righe sono ignorate)
int righe
Numero di righe come parametro extra
✓Le matrici si passano per riferimento implicito: ogni modifica fatta dentro la funzione si vede anche nel chiamante.
⚠Le colonne devono essere costanti note. Per matrici di dimensione qualsiasi serve std::vector (argomento avanzato).
#include <iostream>
using namespace std;

const int COL = 3;

// Stampa una matrice di R righe e COL colonne
void stampa(int m[][COL], int R) {
  for (int i = 0; i < R; i++) {
    for (int j = 0; j < COL; j++) {
      cout << m[i][j] << "\t";
    }
    cout << "\n";
  }
}

// Somma di tutti gli elementi
int somma(int m[][COL], int R) {
  int tot = 0;
  for (int i = 0; i < R; i++)
    for (int j = 0; j < COL; j++)
      tot += m[i][j];
  return tot;
}

int main() {
  int m[2][3] = {{1,2,3}, {4,5,6}};
  stampa(m, 2);
  cout << "Somma: " << somma(m, 2);
  return 0;
}
