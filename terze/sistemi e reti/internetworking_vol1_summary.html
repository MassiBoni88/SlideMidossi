The von Neumann Model

Unit 1 · 01/11
🧠 In 1945 the mathematician John von Neumann proposed an architecture to process and manage data. It is still used in every computer today: technological evolution has changed the single components and their optimisation, not the model.

🔧 The three functional blocks

  • Processor — processes the information
  • Memory — stores data while they are being processed; it holds program instructions, input data, partial results, final results before output, and everything the CPU needs
  • Peripherals — let the microprocessor communicate with the external user, who can enter data or receive information

The components communicate through cables called buses, on which the signals travel.

⚙️ The three execution principles

1
Data and instructions live in a single memory that allows both writing and reading
2
Memory content is addressed by its position, regardless of the type of data or instruction it contains
3
Instructions are executed sequentially

The Buses — System Bus and Chipset

Unit 1 · 02/11
🚌 The set of connections between processor, central memory and peripherals is the System bus: about a hundred wires arranged on the motherboard. Since the parts do very different jobs, it is split into three buses.

📦 Data bus

The lines on which the data travel — both program instructions and actual data.

  • CPU → memory: the CPU writes on the bus, the memory reads
  • Memory → CPU: the memory writes, the CPU reads

Its width depends on the data parallelism of the microprocessor (usually 32 or 64 bit): a 32-bit data bus moves 4 byte in a single operation.

📍 Address bus

Every memory cell and every peripheral has an address, a binary code generated and managed directly by the microprocessor.

On these lines the CPU writes the address of the cell it wants to read or write. It is unidirectional, since the signals are always generated by the CPU.

16 lines → 2¹⁶ = 65 536
          addressable locations
          (64 kB)

🎛️ Control bus

It lets the CPU tell memory and I/O interface what to do at a given moment, and lets it receive requests from peripherals and memory.

Some signals leave the CPU (commands), others enter it (information). Its fundamental task is to synchronise all transfers on the external buses according to the system clock. It is the least homogeneous of the three.

🔢 In many microprocessors a single timed Address/Data bus carries both. A truly "64-bit" machine needs microprocessor, buses and operating system at 64 bit. The number of bits expresses how much data the processor handles at once, and also indicates processing speed and the maximum usable RAM.
🧭 DMA (Direct Memory Access) transfers data to and from memory without involving the microprocessor, freeing the CPU for other work. Performance also improved by splitting the bus into separate buses for fast and slow devices, managed by the chipset: hence the Northbridge (RAM, graphics card, Front-Side Bus) and Southbridge (PCI, SATA, USB, Ethernet, audio, Super I/O).

Cache Memory and Central Memory

Unit 1 · 04/11

⚡ The cache

A hidden memory (from the French caché) that keeps the data the CPU will most likely need soon. It is hidden because it is not managed by the programmer but directly by the microprocessor, through the cache controller.

Much faster, more expensive and smaller than RAM. Originally external, it is now integrated in the chip on three levels: in multi-core CPUs L1 and L2 are private per core, L3 is shared.

📈 Hit rate and replacement

The ratio between cache hits and total memory accesses — the hit rate — measures how effective the cache is.

When the cache is full, space must be freed: the prevailing criterion is LRU (Least Recently Used), discarding the data unused for the longest time.

🔄 Central memory must stay aligned with the cache. Two strategies: write-through, every change in the cache is immediately reported to main memory; write-back, the update happens only when the datum leaves the cache under the LRU criterion. In multiprocessor systems the opposite problem arises — RAM may be more up to date than a private cache — which led to cache coherency protocols.

🧮 Central memory (RAM)

The part of the computer where the program is temporarily kept while it runs, together with all the information it needs.

  • Made of billions of cells, each holding one bit; managed in groups of at least 8 bit (a byte), organised in rows and columns like a giant table — usually in groups of 2 or 4 byte, the word
  • Random access: any byte is reached by generating its physical address, and the access time does not depend on the position
  • Data can be read and written, but are kept only while the machine is powered — it is a volatile memory
💡 "Random" does not mean the datum is stored at a random place: it means the access time does not depend on where it is — the opposite of sequential media such as tape.

Secondary Memories

Unit 1 · 05/11
💾 Also called mass storage: unlike RAM they keep information permanently, have far larger capacity but longer access times. The traditional media were optical and magnetic disks; today the most common are solid state drives.

🧲 Hard disk (HDD)

A direct access magnetic memory: rigid glass or aluminium platters coated with ferromagnetic material.

  • Tracks — concentric rings
  • Cylinder — all tracks at the same distance from the centre across the platters
  • Sectors — fixed-length arcs, separated by gaps

Access time = seek time + rotational latency, so — unlike RAM — the time depends on where the datum is. Desktop drives spin at 5 400 or 7 200 rpm and carry a 32–128 MB buffer cache.

⚡ Flash and SSD

A permanent, rewritable memory made of a semiconductor circuit — no moving parts. Its rise began in the 1990s with the explosion of audio content, when MP3 players and smartphones replaced CDs.

  • SATA SSD — connected through the SATA interface
  • NVMe SSD — connected over PCI Express, going beyond the 550 MB/s ceiling typical of SATA
  • Pen drives — same NAND technology, smaller capacity and lower performance

💿 Optical memories

They exploit the different way laser light reflects off materials to tell 0 from 1. A polycarbonate substrate, an aluminium reflector and protective plastic layers.

Writing burns tiny holes, the pit (0); where the beam does not strike, the surface stays smooth, the land (1). A weaker beam reads them back.

Advantages: immunity to electromagnetic interference, high data stability, longer average life and write protection (ROM or WORM discs). CDs are 12 cm and store data on a single spiral track.

🔌 Hard disks connect to the System bus mainly through EIDE (being abandoned) and SATA; external drives use SATA and USB.

Peripherals and Their Applications

Unit 1 · 06/11
🔌 Peripherals exist to enable the dialogue between the computer and the user. The main classification criterion is the direction of the data flow: towards the processor (input), from the processor (output), in both directions (input/output).

⬅️ Input peripherals

They turn information available in the most varied formats into digital data and send it to the processor.

Keyboarda key press generates a binary code (e.g. ASCII); layouts QWERTY, AZERTY (French), QWERTZ (German), plus function, movement and numeric keys
Mousedetects the roughness of the surface with infrared radiation; characterised by its resolution, the smallest movement it can detect
Trackballa mouse with an integrated ball moved by the operator
Touchpadtouch-sensitive rectangular surface for portable devices
Scannerturns text and drawings on paper into electronic documents

➡️ Output peripherals

They turn the digital data produced by the processor into a form the user can perceive: monitors, printers, plotters, speakers and video projectors.

↔️ Input/Output peripherals

Data travel in both directions: touch screens, network cards, storage devices, modems and multifunction printers.

🧷 Each peripheral is connected through the interface best suited to its transmission speed and to its own characteristics — which is why so many different standards have been developed over the years.

Peripheral Interfacing Standards

Unit 1 · 07/11

🖇️ PCIe — connecting to the CPU

An expansion card is inserted into a PCIe slot, which offers one or more bidirectional serial channels (lanes), so the card can transmit while receiving. Configurations: x1, x2, x4, x8, x16, x32 — an x1 slot is a single lane of 4 wires, one pair to receive and one to send.

A serial bus is faster than a parallel one because the parallel bus must be synchronised on a single clock, while high-speed serial protocols use point-to-point connections with the clock embedded in the exchanged signals. Transfer rate is measured in GT/s (gigatransfer per second).

💽 Mass-storage interfaces

SCSIup to 15 devices; 24.4 m of cable with a single device, 12.2 m with several. Replaced by USB on personal computers
🖥️ Video: VGA (15 pin, analog) · DVI (24 or 29 pin, digital; DVI-I both, DVI-D digital only) · HDMI (19 pin, digital audio and video) · S-Video (4 pin, analog) · Component/RGB (three RCA plugs, analog).

Machine Language and Instruction Format

Unit 1 · 08/11
📟 Every instruction is defined by a special binary code, the opcode, and every CPU has its own set of elementary instructions — the instruction set — which is its specific machine language.

🧱 Why they are "primitive"

  • The concept of data type is almost completely absent
  • The number of operands is limited — generally no more than two or three
  • The number of available operations is fairly small

Using them requires deep knowledge of the physical structure of the machine, because each CPU has its own set. Manufacturers keep backward compatibility: old instructions still run on new processors — faster — while new instructions are not understood by older ones.

🗂️ Fields of a machine instruction

An instruction is a bit string formatted into fields. Every instruction must specify at least the operation (opcode) and the operands involved (or their address).

The Machine Cycle — Fetch-Execute

Unit 1 · 09/11

🔄 The five phases

IF
Instruction Fetch — the address goes from the Program Counter into the Address Register; the instruction is fetched from memory into the Instruction Register; the PC is incremented to point at the next instruction
ID
Instruction Decode — the instruction is decoded and the operands are read from the registers
EX
Execution — the ALU performs the operation
MEM
Memory — the result is written into memory (only for some instructions)
WB
Write Back — the result is written into the proper register and the status is updated

The five phases repeat in sequence until the program ends.

⏲️ Modern microprocessors go beyond the rigid five-phase split: each phase is broken into micro-operations of comparable complexity, each executed in one clock cycle on a continuous stream of data.

🧮 Cycle time and clock frequency

The duration of a micro-operation is the cycle time, written tCPU. Its inverse, 1/tCPU, is the clock frequency, measured in GHz.

Clock = 2 GHz  →  t_CPU = 1/2 GHz = 0.5 ns

instr1  IF  ID  EX  MEM WB
instr2                      IF  ID  EX  MEM WB
instr3                                          IF  ID  EX …

3 instructions × 5 phases × 0.5 ns = 7.5 ns
(sequential execution, no pipeline)

The Pipelining Technique

Unit 1 · 10/11
🚀 Micro-operations are grouped into independent functional units — specialised microcircuits — so the same CPU can process several micro-operations belonging to different units at once. Each independent sequence of processing forms a pipe: the pipeline. 
instr1  IF  ID  EX  MEM WB
instr2      IF  ID  EX  MEM WB
instr3          IF  ID  EX  MEM WB
instr4              IF  ID  EX  MEM WB
instr5                  IF  ID  EX  MEM WB     ← from interval 5 to 8 the five
                                                  functional units all work together

⚠️ The two hazards

  • Data dependency — if an instruction needs the result of a previous one, it cannot enter the EX phase until that instruction has reached WB
  • Execution jumps — blocks of instructions that are skipped unless certain conditions hold. The processor then jumps to instructions stored "far away", and the pipeline must be flushed before the jump, slowing execution down

🛠️ The remedies

  • Dual-port registers: the result is made available at the end of EX, so dependent instructions need not wait for MEM and WB
  • Superscalar technique: several autonomous pipelines in parallel
  • Branch prediction units: circuits that analyse possible jumps and activate pipelines dedicated to the instructions after the jump
  • Splitting an operation into 20–30 elementary steps that execute very quickly, raising the clock frequency

Multi-core CPUs reduced these problems, because every core works autonomously.

Instruction Sets — CISC vs RISC

Unit 1 · 11/11

🏛️ CISC — Complex Instruction Set Computer

The microprocessor can execute complex instructions, which however need long execution times: the clock frequency must stay fairly low and tCPU is high.

Decoding is complex and happens through a resident program — firmware in the control unit — which takes up space and raises the TDP (Thermal Design Power, the heat the cooling system must dissipate, measured in watt).

The instruction set is very wide and narrows the gap between machine language and high-level language. CISC architectures mostly use two operands.

⚡ RISC — Reduced Instruction Set Computer

The instruction set is cut to the minimum, keeping only the indispensable and most frequently used instructions.

The firmware is far simpler and partly made of extremely fast electronic circuits, so the clock frequency can be high and tCPU is low. Unavoidably complex operations are solved by decomposing them into simpler ones.

RISC architectures mostly use three operands and, being designed around few simple instructions easily split into standardised phases, they are ideal for pipelining.

Bootstrap, Firmware and UEFI

Unit 2 · 01/02
⚡ The start-up phase is called bootstrap (or startup): it begins when the power button is pressed and ends when the operating system is running.

🔁 Sequence of events

1
Hardware is powered and the firmware code is loaded into memory for the CPU to execute
2
POST (Power-On Self Test) checks the essential hardware
3
Devices are initialised, drivers loaded into RAM
4
The firmware activates the boot loader, which loads the kernel into a dedicated RAM area

💽 The firmware

Software routines that manage the low-level functionality of the computer, interacting directly with the hardware. It is stored on the motherboard in a flash NVRAM and is the first program executed at power-on.

🖥️ UEFI replaced the BIOS

  • Graphical environment, support for disks larger than 2 TiB, built-in antivirus and much improved security
  • GPT (GUID Partition Table) manages the partitions — no longer limited to four — and keeps a backup of the partition data
  • ESP (EFI System Partition) stores the boot files
  • UEFI Boot Manager drives the bootstrap phase

🔐 Boot security

Secure Boot verifies authenticity and integrity of firmware and OS components during start-up; Windows 11 also requires TPM 2.0, a chip dedicated to managing cryptographic keys.

Multi-boot, Virtualization and the Two Operating Systems

🧭 Two techniques let several operating systems live on the same computer: multi-boot (each OS on its own partition — the UEFI Boot Manager hands control to a third-party boot loader showing a menu) and virtualization (each OS on a dedicated virtual machine).

🧱 Virtualization

More flexible: ideal for temporary tests or for applications that only run on a specific OS version.

Host OSthe OS installed on the physical machine
Guest OSthe OS running inside the virtual machine
Hypervisorthe virtualization software creating the VM
  • Type 1 — bare metal: runs directly on the host with no underlying OS; used for cloud servers and data centres
  • Type 2 — hosted: runs as an application, no direct hardware access; suited to desktop and development — VirtualBox, Hyper-V

🪟 Windows

  • Windows Boot Manager starts winload.efi for a normal boot, winresume.efi when resuming from hibernation
  • Configuration lives in the BCD (Boot Configuration Data)
  • Several installation modes; the most used by administrators is deployment of a system image over the network, another option being the VHD (Virtual Hard Disk)

🐧 GNU/Linux

  • The most widespread boot loader is GRUB2, configurable through a dedicated app or by editing /etc/default/grub and the scripts in /etc/grub.d/
  • The GRUB2 menu appears when several operating systems are installed
  • Ubuntu installs through a guided procedure and can be tried in Live mode from USB or DVD before installing
  • Its recovery mode replaces system files without touching the user files in /home

〰️ Bits travel by varying a characteristic of a physical phenomenon: that variation is the signal.

📈 Analog vs digital

Digital Modulations and QAM

Unit 4 · 02/06
📻 A carrier is combined with a modulating signal, changing one of its parameters; the receiver separates them again. The device doing both is the modem.

🔊 ASK · FSK

ASK — two amplitudes of the carrier; in OOK the carrier is present for 1, absent for 0.

FSK — two carriers at different frequencies. Used by the first modems and by GSM.

🌀 PSK · DPSK

PSK — two phases of the carrier: 0° for 1, 180° for 0.

DPSK — shift relative to the previous bit: 0 = no change, 1 = 180°. Needs a reference signal.

✨ QAM

The only family modulating several bits at a time, acting on the phase alone or on amplitude and phase. Amplitudes are complex numbers on the I/Q axes: the constellation.

number of phases = 2^(number of bits)

4-QAM  dibit     4 phases  → 2 bits    00→0°  01→90°  10→180°  11→270°
8-QAM  tribit    8 phases  → 3 bits
16-QAM quadribit 16 states → 4 bits    12 phases × 4 amplitudes (±A, ±3A)

The Channel — Multiplexing and Line Coding

Unit 4 · 03/06
🛣️ Multiplexing splits one physical medium into several logical channels, so many signals travel simultaneously.

⏱️ TDM

Each frame is divided into slots, one per input device: the channel is distributed instead of granted to one sender at a time.

📶 FDM

The band is split into sub-channels at different frequencies, each working on its own without interfering.

🌈 WDM

Fibre: 80–160 channels on different wavelengths. CWDM 8 channels, cheap optics · DWDM 16–160 around 1550 nm, spacing under 1 nm.

🧵 Line coding

It adapts the digital signal to the medium and keeps synchronism by embedding the clock into the data.

  • NRZ — high for 1, low for 0; long runs of identical bits break synchronism
  • RZ — returns to zero each half period; solves runs of 1s, not of 0s
  • Manchester — a transition per bit, used in local data networks

🔃 The two Manchester conventions

IEEE 802.31 = low-to-high at mid-period; 0 = high-to-low
G.E. Thomasthe exact opposite

A code violation is a missing expected transition, used for signalling.

Error Control

Unit 4 · 04/06
📡 Noise and distortion alter the message. Redundancy codes add bits so the receiver can check the transmission: detection codes reveal that an error occurred, correction codes also say where.

📐 Hamming distance

Number of bits in which two valid codewords differ at the same position; for a code, the minimum among all of them.

detect k errors  →  d = k + 1
correct k errors →  d = 2k + 1

d = 3 → detects double errors, corrects single ones

⚖️ Parity

Distance 2: one check bit makes the number of 1s even or odd. Detects a single error — or an odd number of them — but cannot correct it.

🔄 CRC

The most used in networks for single and multiple errors: 16 or 32 check bits appended to the data.

The m data bits become a polynomial M(x); a standard generator polynomial G(x) of degree r, known to both parties, divides it modulo 2 — the remainder is the CRC.

CRC-CCITT       x¹⁶ + x¹² + x⁵ + 1
CRC-IEEE 802.3  x³² + x²⁶ + x²³ + x²² + …

🩹 Hamming codes

n = m + r          2^r − 1 ≥ m + r

r = 3 → m = 4  → n = 7
r = 4 → m = 11 → n = 15

Check bits go on the positions that are powers of two. The receiver recomputes them and compares by XOR: all zeros → no error, otherwise the result in decimal is the wrong bit's position.

Transmission Media

Unit 4 · 05/06

🌀 Copper

Twisted-pair: copper pairs twisted to cut noise. Cheap, flexible, the fastest copper cable — max 100 m without repeaters, connector RJ45.

UTPunshielded
FTPone outer foil shield
STPa shield per pair

Standards TIA/EIA 568 (T568A / T568B) and ISO/IEC 11801; cat. 5e is the reference. Straight-through between different devices, crossover (pins 1-2-3-6 swapped) between equal ones.

Coaxial — used in early Ethernet (10BASE5 500 m, 10BASE2 185 m), abandoned today. Cross-talk: NEXT and FEXT.

💡 Optical fibre

Spread since the 1990s, it carries the signal with light, exploiting total internal reflection.

  • Core — inner glass, n₁ ≈ 1.5
  • Cladding — outer glass, n₂ ≈ 1.475 (n₁ > n₂)
  • A plastic coating protects the glass

Two fibres per cable — one to transmit, one to receive — so it is full-duplex.

Single mode: one light path, long distances. Multimode: several paths, up to ~3 km. Connectors SC · FC · ST · LC.

📡 Wireless

Transmissions through the air with radio waves (RF) or infrared (IR): no cable at all, the signal is carried by waves emitted from an antenna.

📦 Circuit switching keeps a channel busy even when nobody transmits and runs at the speed of the slowest channel. Packet switching — proposed by Kleinrock in 1961 — uses the channel only when needed: without it, today's Internet traffic would not be sustainable.

Open Systems, Protocols and Standards

🔗 First-generation networks were closed systems: a specialised network for each family of services — the telephone network did not carry data, and vice versa — and machines that could only talk to machines of the same manufacturer. Open systems reversed that.

📜 What a protocol is

A set of formally described rules established to make communication between two or more entities possible. It defines how information is encoded (message format) and the actions to take after sending or receiving a message — including what to do on error.

🌍 What a standard is

A standard provides the guidelines everyone must comply with in order to guarantee the level of interconnection needed for local and international communication.

ISO (International Organization for Standardization) is the most important standards body in the world. Compliance is what guarantees that any network card will work with any other computer on the network — the basis of an open, competitive market.

The Client-Server Paradigm

Unit 5 · 02/08
🖧 The most used paradigm both on the Internet and in most corporate networks. Every application service has a server component and a client component.

🖥️ The server

A process that offers a service and can be reached over the network. It accepts the requests coming from the clients, processes them, performs the requested service and returns the result to the requester — or an error message if it could not satisfy the request. The server process usually stays active all the time.

💻 The client

A process that sends a request to a server and waits for the answer. It typically becomes active only when it has a request to send and, once the answer has arrived, becomes inactive again.

🔁 The five steps

1
The user acts on the client application
2
The client sends the request over the network
3
The server processes the request
4
The server sends back the response
5
The client presents the result to the user
🔐 Networks using this model need a network administrator who manages the servers, performs data backups and enforces the security policies. Corporate networks adopt it precisely because it offers excellent security guarantees. Common examples on the Internet: web browsing, email, file transfer, remote databases.

The Peer-to-Peer Paradigm

Unit 5 · 03/08
🤝 A distributed application model in which the applications act both as server and as client. There is no distinction between server and client computers: every machine has a peer role with respect to the others.

👥 Who decides what

The single users are responsible for the resources of their own computer and decide autonomously which resources — hardware or software — to share.

The model implies the absence of a network administrator, so security is delegated to the individual user: there is no common policy, every computer decides its own data-protection policy.

It applies to fairly small networks, with direct links between the machines.

📜 It all started with Napster, created in 1999 to distribute content — mainly MP3 files. Other widely used P2P programs are JDownloader, eMule and the applications of the BitTorrent network.

Classification of Networks by Extension

Unit 5 · 04/08
📏 Networks can be classified in many ways — by how they are organised, what data they carry, which devices they use, which physical media build the links. One of the most used criteria is their extension, that is the area they can cover.

🏠 LAN — Local Area Network

Not very large, confined to a building or a campus, without crossing public ground. Over time the definition has evolved towards a less physical, more administrative concept: a set of interconnected networks under the control of a single administrative group, which manages security in terms of access control and of the operations that can be performed through the network.

🏙️ MAN — Metropolitan Area Network

Covers the area of a city, a province (metropolitan city) or a small region, and operates at speeds comparable to those of a LAN.

🌍 WAN — Wide Area Network

Geographically extended networks, connecting LANs and MANs scattered around the world. The Internet is the WAN par excellence.

💡 Today's network configurations do not always reflect the rigid LAN/MAN/WAN division: there are networks that are variants or combinations of this classification.

Network Topologies

Unit 5 · 05/08
🧭 The topology defines the structure of the network, specifying how the connected nodes are positioned with respect to each other.

➖ Bus

A single backbone with a terminator resistance at each end. Only one path exists between any pair of nodes, so it is cheap. Signals are checked by every host: only the addressed one processes the message — a broadcast transmission.

If a host fails the network keeps working, but a cable fault stops the whole bus. The single shared channel also prevents two simultaneous transmissions. No longer built today.

⭕ Ring

A cable links each host to the previous and the next one, creating a closed circuit. Suited to local and metropolitan networks — it is the typical MAN topology in fibre.

⭐ Star and extended star

All hosts connect to a central point — usually a hub, switch or router — which becomes the common connection point.

  • Fault tolerance: a fault on one channel or node does not compromise the rest
  • Flexibility and expandability: moving or adding a host does not require stopping the network
  • Simple management

The weak point is the centre: if that device fails, the network stops. Used in local, satellite and radio networks.

The extended star — also called hierarchical or tree — links several stars together and is the most used topology in modern LANs.

🕸️ Full and partial mesh

Full mesh is used when interruptions are absolutely unacceptable: it is completely fault-tolerant, since a fault on a node or a channel does not stop the network — many alternative paths exist.

It is normally used in WANs to connect few, crucial routers at national level: the high number of channels makes it uneconomical for local or metropolitan networks.

Partial mesh has fewer channels — not every node is connected to all the others — but keeps good fault tolerance and lets the designer choose how many channels to use. It is the most used topology in WANs.

Network Devices — NIC, Hub, Switch, Bridge

Unit 5 · 06/08

🔗 NIC — Network Interface Card

The printed circuit that connects the host to the transmission medium; also called LAN adapter. Usually integrated on the motherboard; a second interface can be added as PCIe (desktop) or PC Card PCMCIA / USB (notebook).

Also known as Ethernet cards, since they provide a standard Ethernet port with an RJ45 connector and twisted-pair cable.

Speeds: Ethernet 10 Mbps, Fast Ethernet 100 Mbps, Gigabit 1 Gbps, 10 Gigabit 10 Gbps; Gigabit is also available for fibre.

Every card carries a unique physical address, the MAC address.

🔊 Hub and repeater

The hub receives information from the nodes and forwards it to all its ports except the incoming one — broadcast mode. It cannot tell who the real recipient is, so the receiving devices decide whether to keep or discard the data.

Beyond the useless traffic this creates, it also raises security concerns: every piece of information reaches every connected device, including those it is not meant for.

A hub also works as a multiport repeater: a signal travelling on a physical medium attenuates and gets distorted by noise, so it may need to be regenerated.

🔀 Switch and bridge

The switch analyses the content of the received packet and forwards it only to the real destination, cutting useless traffic and collisions.

During a communication it connects only the two ports involved, so several exchanges run in parallel and the total bandwidth grows.

Modern switches auto-configure: they recognise the device at the other end of the cable, so straight-through cables always work. Hybrid models mix port speeds — e.g. 48 ports 10/100 Mbps plus 2 Gigabit ports.

The bridge is similar but with fewer ports: it splits large networks into subnets for easier management and control, or joins existing LANs into a single corporate network.

Network Devices — Router and Access Point

Unit 5 · 07/08

🌍 The router

A device that makes different and heterogeneous networks talk to each other, routing packets in the right direction. Different networks "speak different languages", so a bridge or a switch is not enough: the router speaks both protocols and reads, translates and forwards (store and forward) the data crossing it.

1
Storing — buffer the packets arriving on each interface
2
Routing — choose the best path towards the destination network
3
Forwarding — put the packets on the correct output interface

Though it can segment a LAN, its main use is as a WAN device. In home networks it usually integrates the modem, giving a single modem-router.

🖥️ A router is a dedicated computer

Being a computer dedicated to routing, it needs an operating system, at least two network cards and:

  • Microprocessor specialised in the required processing
  • RAM (usually DRAM): holds the routing table, the configuration file and the waiting packets; shared between processor memory and I/O memory
  • Flash: erasable, reprogrammable read-only memory holding the operating system; it keeps its content without power

📶 The access point

An AP has a double function: it is a bridge connecting the wired part of the LAN to the wireless part, and it lets wireless terminals join the network, acting as a gateway.

In home networks one AP is usually enough, often doubling as modem-router; if it does not cover the whole flat, a range extender widens the wireless coverage. In corporate networks several APs are cabled together to build a real wireless distribution system, each AP acting as a base station.

Configuring an AP means setting parameters such as the SSID (Service Set Identifier), the name assigned to the wireless network. The reference standard is IEEE 802.11 — Wi-Fi — on the 2.4 GHz and 5 GHz bands.

Cisco Packet Tracer — the Network Simulator

Unit 5 · 08/08
🧪 A network simulator is an application offering components, protocols and management mechanisms that reproduce the behaviour of a complex real network. It emulates devices and systems, lets you build complex topologies graphically and check how traffic flows through them.

🎯 Why simulate

A fully equipped laboratory — with every kind of device, medium and software, in numbers sufficient to build significant physical and logical topologies — is rarely available. A simulator replaces it.

It is useful not only to students, but also to designers and administrators, who can test topologies and configurations before deploying them on the real network: essential when the network must be expanded or a new service offered, to check whether the existing network can support it.

▶️ The two working modes

RT
Realtime — the network behaves as a real one, in real time
SIM
Simulation — an animation of the path the packets follow inside the network, step by step
🔮 A simulator also allows the "what if" analysis: predicting how the system behaves in the face of events that could occur during normal operation.
🏗️ Typical laboratory scenarios: a P2P network built with a simple hub, and a Client-Server network where services such as automatic address assignment are configured.

Local Area Networks and WLANs

Unit 6 · 01/08

✅ What characterises a LAN

  • Small extension — a private area, no public ground crossed
  • High speed — today's Giganet at 1–10 Gbps
  • Low error rate — a consolidated technology
  • Flexibility, modularity, scalability

Most shared resource: the Internet connection. Most common topology: the extended star.

🏢 The network lets hardware (printers, disks) and software resources be centralised, cutting purchase and maintenance costs.

📡 WLAN

Local networks over wireless links; the reference standard is IEEE 802.11, known as Wi-Fi.

Wired and wireless parts coexist. The access point is the base station: where it is placed decides the coverage of the whole area. 802.11ax (Wi-Fi 6) reaches 2.4 Gbps.

🏠 Two typical scenarios

  • Home — one device does everything: modem-router, access point, 4-port switch and firewall. Simple to install, but upgrading one part means replacing the whole box
  • Enterprise — many hosts in extended star: switches for the cable, several access points for coverage, a router with firewall towards the ISP

Transmission Methods and Network Domains

Unit 6 · 02/08

1️⃣ Unicast

One-to-one. If many computers want the same information it is duplicated for each of them, with the risk of increasing traffic.

🎯 Multicast

One-to-many. It saves bandwidth: the information is sent only once and distributed by the switching elements closest to the destinations.

📢 Broadcast

One-to-all: the message reaches every device of the network at the same instant.

💥 Collision domain

The area where two signals can overlap on the channel. Collisions happen in half-duplex, never in full-duplex.

Replacing hubs with switches solved the problem: each computer has its own channel. Security note: inside a collision domain the traffic is shared, so a sniffer can intercept it easily.

📡 Broadcast domain

The hosts that receive a broadcast message. A switch handles broadcast like a hub, so many interconnected switches enlarge the domain and the traffic with it.

Satellite Networks and Geolocation

🛰️ The highest technological level of wireless networks: they connect stations on different continents or in places hard to cable, solving the last mile problem in rural areas.

📻 The transponder

The heart of the satellite: it receives, amplifies and retransmits the signals, receiving on microwaves and retransmitting on different frequencies to avoid interference.

📺 Services and bands

Telecommunications · TV and radio broadcasting · navigation (GNSS) · data sensing for meteorology, split into FSS (fixed) and MSS (mobile).

Quality of Service

Unit 6 · 08/08
🤞 Internet works in best effort mode: no guarantee that a packet arrives, that delivery times are respected, or that packets of a flow arrive in order. Voice and video, played back immediately, cannot live with that.

📊 The parameters

bandwidthmaximum data per unit of time
delaytime between sending and receiving
jittervariation of the arrival time
reliabilitypackets arriving correctly

Router delays: processing · queuing · transmission (L/R) · propagation (d/s).

🔧 Two ways to guarantee it

Overprovisioning — expensive but effective: resources dimensioned so that congestion cannot occur.

Traffic treatment — four phases: classification · admission control (edge router) · marking · scheduling and dropping.

Without QoS a simple FIFO would do; Priority Queueing serves the high-priority queues first, at the risk of starving the low-priority traffic.

🏛️ The two IETF architectures

IntServ — flow-based: resources are reserved for the single flow through the RSVP protocol. Accurate, but it does not scale over hundreds of thousands of flows.

DiffServ — class-based: flows are grouped into classes marked in the header. Edge routers classify and mark, core routers forward the aggregate flows. It scales, but lacks the dynamic reservation of IntServ.

arp   = ARP(pdst="192.168.1.0/24")
ether = Ether(dst="ff:ff:ff:ff:ff:ff")

for sent, received in answered:
    print(received.psrc, received.hwsrc)

Cyberspace and Cybercriminals

Unit 8 · 01/06
🌌 The cyberspace is the virtual space in which users and programs, connected through a network such as the Internet, move and interact for the most varied purposes.
🔀 What happens online is no less real than what happens offline: the term onlife, coined by Luciano Floridi, describes life in a hyper-connected world — the infosphere.

🧩 Complexity generates vulnerability

Thousands of networks plus forty years of stratified software and protocols make it the most complex thing humankind has ever built. That complexity generates vulnerabilities — bugs, wrong configurations, weak protocols — which criminals exploit.

It is also a space populated by an infinity of data: the world of Big Data.

🕰️ From the lone hacker…

In the early years the typical criminals were teenagers or hobbyists operating from the home PC, committing small offences to prove their skill.

💥 …to organised gangs

Today we face fierce organisations with considerable means, able to damage not only citizens and companies but the economy of an entire country, striking government sites, media and businesses.

⚔️ Cybercrime

Every threat or attack carried out through the network: all crimes that use computer systems and digital technologies to damage a person, a company or an organisation.

An attack is an unauthorised action against the confidentiality, integrity or availability of the assets of an organisation.

Ransomware and Social Engineering

Unit 8 · 04/06

🔒 Ransomware

Once inside the servers it encrypts the data or blocks access to the systems, and self-propagates through the network. To get the data back the victim must pay a ransom in cryptocurrency.

To prove the breach the criminals publish part of the stolen data, threatening to release everything they exfiltrated.

💰 The RaaS model

The most organised gangs adopt Ransomware-as-a-Service: affiliates deposit money for commissioned attacks and take up to three quarters of the ransom, the rest going to the developers.

In 2023 Italy ranked fourth among the most targeted countries.

🎭 Social engineering pushes people to hand over personal information or to allow access to a computer. It exploits the human factor, the most important vulnerability of the whole macrosystem.

Vishingthrough a voice call — a fake ISP technician reporting a virus

Piggybackingfollowing an authorised person into a restricted area

The Defenders

Unit 8 · 05/06

🛡️ A harder world to defend

Before the cyberspace, information lived on paper or on isolated computers inside a well-defined perimeter — the data centre — which allowed precise threat models and clear security policies.

In the cyberspace threats mutate continuously and many stay unknown for months or years, so policies must be written with deeply incomplete information.

⚖️ The asymmetry

  • Attackers share information, defenders tend to keep silent
  • The defender must protect every point, the attacker picks the weakest one
  • The defender covers known attacks, the attacker hunts for unknown vulnerabilities

🎓 Awareness

Companies train their staff on the risky behaviours to avoid: enabling macros in attachments, following suspicious links, installing software from uncertified sites.

The goal is that everyone, whatever their role, acquires the basic methods of information security — to prevent and, when needed, to defend.

💾 Against ransomware

An infection can be devastating and recovery is a hard, laborious process that is not always guaranteed. The first preventive measure is a backup and recovery plan for all critical information.

⚠️ Cybersecurity must be part of the business, not an afterthought: companies fall into two categories — those that have suffered attacks, and those that have and do not know it.

Analysis can be live or later from the PCAP file — the more common choice. In promiscuous mode the card passes on all the traffic it receives. Capture filters act during collection, display filters on what is shown.

🚩 Ethical hacking means hacking carried out in a controlled, planned way and with no malicious purpose. In a CtF the flag is a code: a sequence of characters hard to guess and hard to find.

🎲 The two formats

  • Jeopardy — no direct attack between teams: challenges in different categories (web, networks, cryptography, binary) on vulnerable targets built by the organisers
  • Attack/Defense — all against all: every team gets the same vulnerable virtual machine and must steal the others' flags while protecting its own

The two can be combined into mixed CtFs; at the end participants publish their write-ups.

🇮🇹 The Cybersecurity National Lab of CINI runs The Big Game: OliCyber, the Italian Cybersecurity Olympics for secondary schools, and CyberChallenge. Wireshark and Python are two of the tools these competitions train on.

Final Recap — Units 1 to 4

Recap · 01/02

🔵 U1 — The Computer System

  • von Neumann: processor + memory + peripherals; single memory, addressing by position, sequential execution
  • Buses: data (32/64 bit parallelism), address (unidirectional, 2ⁿ locations), control (synchronises on the clock) · DMA · chipset Northbridge/Southbridge
  • CPU blocks ALU · CU · LCU · registers · cache · MI; registers PC · IR · AR · DR · flags
  • Memory: L1/L2/L3 cache (hit rate, LRU, write-through/write-back) → RAM → HDD (tracks, cylinders, sectors, seek + latency), SSD/NVMe, flash, optical
  • Peripherals input / output / I-O · standards PCIe, SATA, SCSI, USB 1.0→4.V2, HDMI, RJ45
  • Machine language: opcode + operands, architectures with 1/2/3 operands
  • Machine cycle IF · ID · EX · MEM · WB; tCPU and clock frequency
  • Pipelining: data dependency and jumps → dual-port registers, superscalar, branch prediction, multi-core
  • CISC wide set, 2 operands · RISC reduced set, 3 operands, high clock

🟢 U2 — From Power-On to the OS

  • Bootstrap: power on → firmware + POST → drivers → boot loader → kernel
  • UEFI: GUI, disks > 2 TiB, GPT, ESP, Secure Boot, TPM 2.0
  • Multi-boot vs virtualization (Host OS + Guest OS + hypervisor type 1 / type 2)
  • Boot loaders: Windows Boot Manager + BCD · GRUB2, Live and recovery modes

🟡 U3 — Programming in Assembly

  • Mnemonic codes → assembler + linker → executable
  • Intel 8086: FR · AX BX CX DX · DS ES CS SS · DI SI · IP BP SP
  • Addressing immediate, direct, indirect — 7 modes; EMU8086 and the structured constructs

🔴 U4 — Basics of Network Communication

  • Analog signal (amplitude, frequency, phase) vs digital signal (discrete values, instant transitions)
  • simplex / half-duplex / full-duplex · bandwidth (theoretical) vs throughput (real)
  • Modulations ASK · FSK · PSK · DPSK — one bit each; QAM several bits per baud, I/Q constellation
  • Bit rate = Baud rate × bits per baud; phases = 2^bits
  • Multiplexing TDM · FDM · WDM (CWDM 8 ch, DWDM 16–160 @ 1550 nm)
  • Line coding NRZ · RZ · Manchester (802.3 and G.E. Thomas)
  • Errors: Hamming distance — detect k → d = k+1, correct k → d = 2k+1; parity, CRC, Hamming codes (XOR gives the wrong position)
  • Media: UTP/FTP/STP cat. 5e–8, 100 m, RJ45, straight vs crossover · coax · fibre core/cladding, SM and MM · wireless RF and IR
  • Access: PSTN 64 kbps · ISDN BRI / PRI · ADSL DMT 256 sub-channels · FTTH/FTTC/FWA
  • Switching circuit · packet · virtual circuit

Final Recap — Units 5 to 8

Recap · 02/02

🔵 U5 — Network Technology

  • From closed to open systems: protocols (syntax · semantics · timing) and standards (ISO)
  • Client-Server: server always active, client active on request; administrator, backup, security policies
  • Peer-to-Peer: every node is client and server, no administrator, small networks
  • Classification LAN · MAN · WAN; topologies bus, ring, star, extended star (LAN), partial mesh (WAN)
  • Devices: NIC (MAC address) · hub · switch · bridge · router (storing, routing, forwarding) · access point (SSID)
  • Packet Tracer: "what if" analysis in Realtime and Simulation mode

🟢 U6 — Telecommunication Networks

  • LAN: 1–10 Gbps, extended star; WLAN IEEE 802.11, Wi-Fi 6 up to 2.4 Gbps; home and enterprise scenarios
  • unicast · multicast · broadcast; collision domain (1 per switch port) and broadcast domain (1 per router port)
  • Ethernet: ALOHAnet 1971 → Metcalfe 1976 → DIX 1980 → IEEE 802.3 1985; 10BASE5 → 800GBASE
  • MAN 5–100 km, fibre rings; wireless with WiMAX (802.16), LOS and NLOS
  • WAN: access → metro/regional (POP) → backbone; ISP hierarchy up to the IXP; ULL
  • Satellites: transponder; GEO 36 000 km · MEO · LEO constellations · SSO · HEO; bands L to Ka; GNSS/GPS with multilateration
  • QoS: best effort; bandwidth · delay · jitter · reliability; overprovisioning vs traffic treatment; IntServ (RSVP) vs DiffServ (classes, aggregate flows)

🟡 U7 — Automation with Python and AI

  • Plan management and automation from the very start: configuration, data collection, reporting, troubleshooting
  • AI: predict failures from historical data, forecast peaks with machine learning, proactive operations
  • Python (van Rossum, 1991): interactive interpreter, IDLE, VS Code with linting, virtual environment per project
  • Modules (.py) and packages (directory + __init__.py), pip and PyPI
  • GeoPy (Nominatim / OpenStreetMap) · Scapy (ARP, Ether) for host discovery

🔴 U8 — Cybersecurity: the Basics

  • Cyberspace, the onlife experience and Big Data; complexity generates vulnerability
  • From the lone hacker to organised gangs; assets tangible and intangible
  • CIA triad plus resilience, non-repudiation, authenticity (ISO/IEC 27000)
  • Three fronts — technology, organisation, human factor — and the five NIST phases identify · protect · detect · respond · recover
  • Attacks: interception · alteration · falsification · sabotage; malware (virus, worm, trojan, spyware)
  • Ransomware and the RaaS model; social engineering (phishing, spear phishing, whaling, vishing)
  • Defenders: structural asymmetry, awareness training, backup plans
  • Wireshark: three phases, PCAP, promiscuous mode, capture and display filters · CtF Jeopardy and Attack/Defense (OliCyber, CINI)
