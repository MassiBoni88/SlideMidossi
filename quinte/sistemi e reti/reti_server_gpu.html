Cablaggio Strutturato — ISO/IEC 11801

03/14

🔵 CD — Campus Distributor

Centro stella di comprensorio. Cervello centrale dell'intera rete di campus. Ce n'è uno solo. Distanza massima verso BD: 2000 m.

🟢 BD — Building Distributor

Centro stella di edificio. Nodo principale di ogni edificio. Distribuisce ai piani. Distanza massima verso FD: 500 m.

🔴 FD — Floor Distributor

Centro stella di piano. L'armadio rack di piano. Distanza massima verso TO: 90 m.

⬜ TO — Telecommunication Outlet

Presa RJ-45 a muro. Dal TO al dispositivo finale (cavo patch): max 5 m.

UTP vs STP

  • U/UTP: nessuna schermatura — economico, diffusissimo
  • F/UTP: foglio esterno — uffici con molti apparati
  • S/FTP: treccia + foglio su coppie — ambienti industriali
  • ⚠️ STP funziona solo con messa a terra corretta

Perché la fibra nelle dorsali?

  • 🚀 Banda superiore: la dorsale aggrega traffico di tutti i piani — fino a 100 Gbps+ con fibra vs 10 Gbps rame
  • 🔮 Scalabilità futura: il cavo non si cambia per decenni, solo gli apparati alle estremità
  • ⚡ Isolamento galvanico: nessun rischio corrente tra edifici (fulmini, guasti)
  • 📡 Immunità EMI: ignora motori ascensori, quadri elettrici, climatizzatori
  • 💰 Costo d'installazione: nei cavedi si installa una volta sola
✅ La scelta fibra/rame non dipende solo dalla distanza ma da capacità, sicurezza elettrica e investimento a lungo termine. La dorsale è il punto più critico e difficile da modificare.
⚠️ La fibra nel cablaggio orizzontale si usa raramente: serve PoE, la distanza è breve, i dispositivi hanno solo porte RJ-45 e il costo è elevato.

Tipologie di Server — Form Factor

05/14

🖥️ Tower

es. IBM System x3100 M4

  • Come un PC da ufficio grande, verticale
  • Non serve rack o sala server
  • Silenzioso, economico
  • Facile da espandere (HDD, schede)
🏫 Usato da: piccole aziende, studi professionali, scuole

📦 Rack

es. Dell PowerEdge R710 (2U)

  • Piatto, si inserisce in armadio 19"
  • Altezza in U (1U = 4,45 cm)
  • Standard universale, impilabili
  • Molto rumoroso, serve sala server
🏢 Usato da: aziende medie e grandi, data center

🔪 Blade

es. HP BladeSystem c7000 (16 lame)

  • Lame sottili in uno chassis comune
  • Alimentatori, ventole, switch condivisi
  • Densità elevatissima, cablaggio minimo
  • Chassis costoso, vendor lock-in
🏭 Usato da: grandi aziende, cloud provider, data center

Ruoli dei Server in Azienda

06/14

📁 File Server

Condivide file in LAN via SMB/CIFS (Windows) o NFS (Linux). Appare come unità di rete (es. Z:\). Modifica diretta sul server, integrato con Active Directory.

📡 FTP Server

Trasferisce file con protocollo FTP (porta 21). Scarichi → modifichi → ricarichi. Usato per scambio con esterni. FTP classico in chiaro → preferire SFTP o FTPS.

🌐 Web Server

Serve contenuto statico via HTTP/HTTPS. HTML, CSS, immagini. Nessuna elaborazione dati. Software: Apache, Nginx, IIS.

⚙️ Application Server

Esegue logica applicativa dinamica. Si connette al database, autentica utenti, elabora transazioni. Software: Tomcat, Node.js, Django.

✉️ Mail Server

Gestisce posta elettronica. Deve essere raggiungibile da Internet (porta 25 SMTP) → si colloca in DMZ per isolare la LAN interna da possibili compromissioni.

🏛️ Active Directory (DC)

Gestisce centralmente utenti, computer, policy (GPO) e risorse. Autenticazione via Kerberos/LDAP. Sta sempre nella LAN interna, mai esposto.

🖥️ VNC Server

Controllo desktop remoto via protocollo RFB (porta 5900). Non usa Telnet. Trasmissione in chiaro → usare sempre dentro SSH tunnel o VPN. Mai esposto su Internet.

⚠️ Web Server + Application Server lavorano insieme: Nginx serve i file statici, passa le richieste dinamiche a Node.js/Django che interroga il DB.

DMZ — DeMilitarized Zone

07/14

Cos'è la DMZ

Sottorete separata tra Internet e la LAN interna, protetta da due firewall. I server pubblici stanno qui: accessibili dall'esterno ma isolati dalla rete interna in caso di attacco.

  Mail · Web · FTP · DNS

🛡️ Il mail server sta in DMZ perché la porta 25 SMTP deve essere aperta verso Internet. Se compromesso, l'attaccante è bloccato dal firewall interno.

CPU vs GPU — Filosofie diverse

08/14

🧠 Core CPU — pochi ma potenti

Ogni core è un processore complesso e sofisticato. Gestisce logica condizionale, eccezioni, memoria virtuale, esecuzione fuori ordine.

  • 8–64 core in una CPU moderna
  • Clock: 3–5 GHz
  • Ideale per: lavoro sequenziale complesso
👨‍⚕️ La CPU è come un chirurgo specialista: fa operazioni complesse, una alla volta, con grande precisione.

⚡ Core GPU — tanti ma semplici

Ogni core è un'unità piccola e semplice che sa fare poche cose: principalmente moltiplicazioni e addizioni tra numeri in parallelo.

  • 10.000+ core in una GPU moderna
  • Clock più basso, ma in parallelo massiccio
  • Ideale per: stessa operazione su milioni di dati
🏭 La GPU è come un operaio in catena di montaggio: fa un'operazione semplice, ma in migliaia contemporaneamente.

Perché la GPU vince per l'AI

Il calcolo AI è essenzialmente moltiplicazione tra matrici — miliardi di operazioni identiche su dati diversi. Con 16.000 core GPU le fai tutte contemporaneamente. Con 16 core CPU le fai una alla volta.

CUDA · Tensor · RT Core — Le differenze

09/14

⚡ CUDA Core

Compute Unified Device Architecture

  • Core generico base della GPU
  • Addizioni e moltiplicazioni su singoli numeri
  • Qualsiasi calcolo parallelo
  • H100 SXM5: 16.896 CUDA core
🔧 Presente da sempre. Prima che esistessero i Tensor core, tutto il calcolo AI passava di qui.

🧮 Tensor Core

Introdotti con Volta (2017)

  • Moltiplicazione di intere matrici in un ciclo
  • Operazione FMA su matrici 4×4
  • ~15× più veloci dei CUDA per AI
  • H100 SXM5: 528 Tensor core
🤖 Fondamentali per training e inferenza AI. Supportano FP8, FP16, BF16, INT8.

🔆 RT Core

Introdotti con Turing (2018)

  • Accelerano il ray tracing in tempo reale
  • BVH traversal: capisce quali oggetti colpisce un raggio
  • Usati solo per grafica 3D
  • H100 SXM5: 792 RT core
💡 Nell'H100 (GPU solo AI) gli RT core ci sono ma non vengono mai usati. Come un'auto da corsa col portabagagli.

Cos'è un TFLOP?

FLOP = Floating Point Operation = una singola operazione matematica su numeri decimali (es. 3.14 × 2.71).

TFLOPS = Tera FLOPS = 1.000 miliardi di operazioni al secondo.

Quando si usa quale precisione?

  • FP64: calcolo scientifico (fisica, simulazioni) — massima precisione
  • FP16/BF16: training AI — buon equilibrio velocità/precisione
  • FP8/INT8: inferenza AI — velocità massima

Transformer Engine

Feature esclusiva dell'H100: sceglie automaticamente tra FP8 e FP16 layer per layer durante il training, ottimizzando velocità e precisione senza intervento manuale.

NVLink — GPU a GPU

Interconnessione proprietaria NVIDIA. Nell'H100: 900 GB/s di banda GPU-to-GPU. Permette a 8 GPU in un DGX di lavorare come un'unica GPU enorme.

Costo

Una singola H100 SXM5: circa 30.000–40.000 $. Un sistema DGX H100 (8 GPU): circa 300.000 $. Un cluster da 10.000 GPU: oltre 300 milioni $.

Training vs Inferenza — Bit e Potenza di Calcolo

12/15

🔴 Training — addestrare il modello

  • Scopo: calcolare e aggiornare miliardi di parametri (pesi)
  • Precisione usata: FP16 / BF16 (16 bit)
  • Perché 16 bit? Serve abbastanza precisione per aggiornare i pesi correttamente, ma meno memoria e più velocità rispetto a FP32
  • Potenza richiesta: massima — si usano migliaia di GPU per settimane o mesi
  • Costo energetico: altissimo, non ripetibile spesso
  • Si fa: una volta sola (o raramente, per nuove versioni)

🟢 Inferenza — rispondere agli utenti

  • Scopo: usare il modello già addestrato per generare risposte
  • Precisione usata: FP8 / INT8 (8 bit)
  • Perché 8 bit? Il modello è già addestrato — la precisione ridotta introduce errori trascurabili ma raddoppia la velocità e dimezza la memoria
  • Potenza richiesta: minore del training, ma sempre attiva 24/7
  • Si fa: continuamente, ad ogni richiesta utente

  • Web server vs App server: statico vs logica dinamica
  • VNC vs Telnet: desktop grafico vs riga di comando
  • CPU core vs GPU core: complesso/pochi vs semplice/tantissimi
  • CUDA vs Tensor: generico vs matrici per AI (15× più veloce)

🟢 Cablaggio Strutturato

  • Gerarchia: CD → BD → FD → TO con distanze massime 2000/500/90/5 m
  • VCC (verticale/dorsale) usa fibra · HCC (orizzontale) usa rame Cat.6A

🔵 Server Aziendali

  • Tower (PMI) · Rack (aziende) · Blade (data center)
  • File server (SMB/LAN) vs FTP (Internet/esplicito)
  • Web server (statico) + App server (logica) + DB = stack completo
  • Mail server in DMZ · Active Directory nella LAN interna

🔴 GPU e Hardware AI

  • CPU: pochi core complessi · GPU: migliaia di core semplici in parallelo
  • CUDA core (generico) · Tensor core (AI, 15× più veloce) · RT core (grafica)
  • H100 SXM5: 16.896 CUDA · 528 Tensor · 792 RT
  • TFLOPS dipende dalla precisione: FP64 (34T) → FP8 (3.958T)
  • Training: FP16/BF16 — massima precisione, settimane, migliaia di GPU
  • Inferenza: FP8/INT8 — velocità massima, millisecondi, 24/7

🟡 Cluster AI

  • Training vs Inferenza: cluster enormi vs cluster sempre attivi
  • InfiniBand 400 Gbps vs Ethernet 10 Gbps aziendale
  • Raffreddamento a liquido, consumo energetico enorme
  • Google TPU, AWS Trainium: chip proprietari per AI
