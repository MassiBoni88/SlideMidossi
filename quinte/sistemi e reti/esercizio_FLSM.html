Esercizio: Subnetting a Maschera Fissa

Suddivisione di una rete di Classe B in sottoreti di uguale dimensione — calcolo maschera, block size, host e gateway.

▶ Scenario

L'azienda TechNord S.r.l. ha ottenuto dall'ISP l'indirizzo di rete 172.18.0.0/16. L'amministratore di rete deve suddividerla in 4 sottoreti di uguale dimensione, una per ogni reparto:

  • Reparto 1 — Produzione
  • Reparto 2 — Amministrazione
  • Reparto 3 — Vendite
  • Reparto 4 — IT

Per ogni sottorete il gateway è il primo indirizzo host disponibile. Ogni reparto è collegato a un'interfaccia dedicata del router centrale.

Classe B 4 sottoreti FLSM Gateway = primo host
▶ Domande
1.
A quale classe appartiene la rete 172.18.0.0? Qual è il range del primo ottetto per quella classe? Qual è la subnet mask di default in notazione decimale puntata e CIDR?
2.
Quanti bit occorre prendere in prestito dall'Host ID per ottenere almeno 4 sottoreti? Mostra il ragionamento con la formula 2n.
3.
Qual è la nuova subnet mask in notazione CIDR (es. /xx) e in decimale puntata (es. 255.x.x.x)?
4.
Qual è il block size? In quale ottetto cambia l'indirizzo passando da una sottorete alla successiva? Come si calcola?
5.
Quanti host sono utilizzabili per ogni sottorete? Applica la formula 2h − 2.
6.
Completa la tabella delle sottoreti con: indirizzo di rete, primo host, ultimo host, broadcast e gateway per ciascun reparto.
7.
L'host con indirizzo IP 172.18.75.10 a quale sottorete appartiene? Qual è il suo gateway? Mostra come hai determinato l'appartenenza.

✓ Risposta 1 — Classe e maschera di default
ⓘ 172.18.0.0 appartiene alla Classe B: il range del primo ottetto è 128–191 (i primi due bit sono sempre 10). La subnet mask di default è /16 = 255.255.0.0.
✓ Risposta 2 — Bit da prendere in prestito
Sottoreti richieste: 4
2n ≥ 4  →  21 = 2 (no)  ·  22 = 4 (sì)  →  n = 2 bit
⚠ Con n = 2 si ottengono esattamente 4 sottoreti. Se servissero 5 o 6, occorrerebbe n = 3 (2³ = 8 sottoreti).
✓ Risposta 3 — Nuova subnet mask
Maschera originale: /16
Bit presi in prestito: n = 2
Nuova maschera: /16 + 2 = /18

Conversione in decimale:
/18  →  11111111.11111111.11000000.00000000
         255     .   255  . 192    .   0

255.255.192.0
✓ Risposta 4 — Block size
L'ottetto modificato dalla maschera è il TERZO ottetto (192).

Block size = 256 − 192 = 64

Le reti si susseguono aumentando il 3° ottetto di 64:
172.18.0.0  /18
172.18.64.0 /18
172.18.128.0/18
172.18.192.0/18
✓ Risposta 5 — Host per sottorete
Nuova maschera: /18  →  bit per host: h = 32 − 18 = 14
Host utilizzabili = 214 − 2 = 16384 − 2 = 16.382 host
✓ Ogni sottorete /18 può ospitare fino a 16.382 host — ampiamente sufficiente per qualsiasi reparto aziendale di medie dimensioni.

✓ Risposta 7 — Appartenenza di 172.18.75.10
IP da analizzare: 172.18.75.10
Block size: 64 nel 3° ottetto

Confini delle sottoreti (3° ottetto):
Sottorete 1:  0   ≤ x <  64  →  172.18.0.x
Sottorete 2: 64  ≤ x < 128  →  172.18.64.x  ← 75 è qui
Sottorete 3: 128  ≤ x < 192  →  172.18.128.x
Sottorete 4: 192  ≤ x < 256  →  172.18.192.x
