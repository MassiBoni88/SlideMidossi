Struttura di un indirizzo IPv4

SEZIONE 01

32 bit in 4 ottetti

Un indirizzo IPv4 è composto da 32 bit scritti come 4 gruppi di 8 bit (ottetti) separati da punti in notazione decimale. Ogni ottetto va da 0 a 255.

Indirizzo: 192.168.1.10

Binario:
11000000.10101000.00000001.00001010
   192   .   168    .     1    .    10

4 ottetti × 8 bit = 32 bit totali
Valori possibili: 0.0.0.0 → 255.255.255.255

Net ID e Host ID

Ogni indirizzo è diviso in due parti:

  • Net ID — identifica la rete a cui appartiene l'host. Tutti gli host nella stessa rete condividono lo stesso Net ID.
  • Host ID — identifica univocamente il singolo dispositivo all'interno della rete. Deve essere unico nella rete.

Indirizzi speciali in ogni rete

  • Indirizzo di rete — host ID tutto a 0 → non assegnabile. Es: 192.168.1.0
  • Broadcast — host ID tutto a 1 → pacchetti a tutti gli host. Es: 192.168.1.255
  • Host assegnabili = 2n − 2 (dove n = bit dell'host ID)
ⓘ Per una rete /24 (host ID = 8 bit): 28 − 2 = 254 host assegnabili. Si sottraggono 2 per escludere l'indirizzo di rete e il broadcast.

Indirizzi Pubblici

Tutti gli indirizzi non riservati sono pubblici. Sono assegnati da IANA (Internet Assigned Numbers Authority) e devono essere univoci su tutto Internet. Un dispositivo può comunicare direttamente su Internet solo con un IP pubblico.

NAT — Network Address Translation

Il NAT permette a più dispositivi con IP privati di condividere un unico IP pubblico. Il router sostituisce l'IP sorgente privato con il suo IP pubblico nei pacchetti in uscita, e viceversa per le risposte in entrata.

Schema tipico di una rete domestica:

  [ PC: 192.168.1.10 ]  ─┐
  [ PC: 192.168.1.11 ]  ─┤  Router NAT  ─── Internet
  [ PC: 192.168.1.12 ]  ─┘  (IP pubblico: 87.21.45.3)

Tutti e tre i PC escono con l'IP 87.21.45.3
ⓘ Altri indirizzi speciali: 127.0.0.1 (loopback), 0.0.0.0 (rete corrente / rotta di default), 169.254.x.x (APIPA — assegnato automaticamente quando il DHCP non risponde).

Il Gateway

SEZIONE 03

Cos'è il Gateway?

Il gateway (o default gateway) è il dispositivo — solitamente un router — che funge da "porta di uscita" della rete locale verso altre reti o verso Internet. Quando un host deve comunicare con un indirizzo esterno alla propria rete, invia il pacchetto al gateway.

Come sceglie l'host dove mandare i pacchetti?

  • Stessa rete: l'host confronta il proprio IP con la subnet mask. Se il destinatario è nella stessa rete → consegna diretta (ARP).
  • Rete diversa: il pacchetto viene inviato al default gateway, che provvede a instradarlo.
Verifica di appartenenza alla stessa rete:

IP mittente:      192.168.1.10
Subnet mask:      255.255.255.0  (/24)
IP destinatario:  192.168.1.80

→ Stessa rete (terzo ottetto = .1) → consegna diretta

IP destinatario:  10.0.0.5
→ Rete diversa → pacchetto al gateway

La Subnet Mask

SEZIONE 03

Cos'è la Subnet Mask?

La subnet mask è un numero da 32 bit in cui i bit impostati a 1 identificano la parte di rete (Net ID) e i bit a 0 identificano la parte host (Host ID). Applicata in AND con l'IP, estrae l'indirizzo di rete.

Notazione decimale puntata:
255.255.255.0

In binario:
11111111.11111111.11111111.00000000
 ← 24 bit di rete →  ← 8 bit host →

Notazione CIDR (Classless Inter-Domain Routing):
/24   ← numero di bit a 1 nella maschera

AND bit a bit — estrazione dell'indirizzo di rete

Per trovare l'indirizzo di rete di un host si esegue l'AND logico tra l'IP e la subnet mask. Dove la maschera ha 1 il bit dell'IP viene conservato; dove ha 0 il bit viene azzerato.

Esempio: IP 192.168.1.70 con maschera /26

IP:   11000000.10101000.00000001.01000110
      192      .  168    .   1    . 70

Mask: 11111111.11111111.11111111.11000000
      255      .  255    .  255   . 192

AND:  11000000.10101000.00000001.01000000
      192      .  168    .   1    . 64

→ Indirizzo di rete: 192.168.1.64
ⓘ Con /26 l'ultimo ottetto della maschera è 192 = 11000000: i 2 bit più significativi diventano parte del Net ID, lasciando 6 bit per l'Host ID (26 − 2 = 62 host).
✓ Regola pratica CIDR: se la maschera è /x, i primi x bit identificano la rete, i restanti (32 − x) bit identificano gli host nella sottorete.

Subnetting — Perché e Come

SEZIONE 04

Cos'è il Subnetting?

Il subnetting consiste nel dividere una rete IP in sottoreti più piccole "prendendo in prestito" bit dall'Host ID per creare nuovi Net ID di sottorete. La maschera viene allungata: più bit a 1 = reti più piccole.

Perché si fa?

  • Sicurezza — isolare segmenti di rete (es. server da client)
  • Efficienza — evitare sprechi di indirizzi IP
  • Performance — ridurre il dominio di broadcast
  • Organizzazione — separare reparti o sedi diverse
Rete originale /24 → divisa in 4 sottoreti /26

Rete: 192.168.1.xxxxxxxx   (/24)
       ←   24 bit net   → ←  8 host  →

Dopo subnetting /26:
192.168.1.00xxxxxx  → sottorete 1 (.0)
192.168.1.01xxxxxx  → sottorete 2 (.64)
192.168.1.10xxxxxx  → sottorete 3 (.128)
192.168.1.11xxxxxx  → sottorete 4 (.192)

FLSM — Maschera Fissa (Fixed Length Subnet Mask)

SEZIONE 05

Come funziona l'FLSM

Con FLSM si sceglie un'unica subnet mask da applicare a tutte le sottoreti. Si prendono n bit dall'Host ID per creare le sottoreti. Tutte le sottoreti risultanti hanno:

  • Stesso numero di host disponibili
  • Stessa subnet mask
  • Block size costante tra un indirizzo di rete e il successivo

Procedimento passo per passo

  1. Determinare quante sottoreti servono → calcolare n bit (2n ≥ sottoreti)
  2. Nuova maschera = maschera originale + n
  3. Block size = 256 − valore ottetto maschera modificato
  4. Elencare le sottoreti incrementando di block size
  5. Per ogni sottorete: rete, primo host, ultimo host, broadcast
ⓘ Per trovare la maschera minima che supporti almeno K sottoreti: scegli n tale che 2n ≥ K. Per ≥ 4 sottoreti: n = 2. Per ≥ 8 sottoreti: n = 3. Per ≥ 16 sottoreti: n = 4.

Quando conviene l'FLSM?

L'FLSM è indicato quando tutte le sottoreti hanno circa lo stesso numero di host. Se una rete ha 100 host e un'altra 5, la maschera fissa sprecherà molti indirizzi nella sottorete più piccola.

Esempio rapido: 3 sottoreti → n = 2 (2²=4)
Rete: 10.0.0.0/8  →  /10

Nuova mask: /10 = 255.192.0.0
Block size: 256 − 192 = 64 (nel 2° ottetto)

Sottorete 1:  10.0.0.0  /10
Sottorete 2:  10.64.0.0 /10
Sottorete 3:  10.128.0.0/10
Sottorete 4:  10.192.0.0/10

Host per rete: 2²² − 2 = 4.194.302
⚠ Il block size nel quarto ottetto vale sempre 256 − valore decimale ultimo ottetto della maschera. Per /26 (maschera .192): block size = 256 − 192 = 64. Le reti iniziano a .0, .64, .128, .192.

VLSM — Maschera Variabile (Variable Length Subnet Mask)

SEZIONE 06

Cos'è il VLSM?

Il VLSM permette di assegnare a ogni sottorete una maschera di lunghezza diversa, dimensionata esattamente al numero di host necessari. Evita gli sprechi tipici dell'FLSM quando le reti hanno esigenze molto diverse.

Procedimento VLSM

  1. Elencare le sottoreti in ordine decrescente di host richiesti
  2. Partire dall'indirizzo base della rete originale
  3. Per ogni sottorete: trovare la maschera minima che contenga gli host richiesti (2h − 2 ≥ N)
  4. Allocare la sottorete e avanzare all'indirizzo successivo disponibile
  5. Ripetere fino all'ultima sottorete
✓ Regola d'oro VLSM: allocare sempre dalla più grande alla più piccola. Iniziare dalla più piccola sprecherebbe spazio contiguo che potrebbe servire per le reti grandi.

Formule chiave

N° sottoreti  = 2n      (n = bit prestati)
Host per rete = 2h − 2   (h = bit host rimasti)
Nuova mask   = /old + n
Block size    = 256 − valore ottetto mask
Prossima rete = rete corrente + block size

Concetti da ricordare

  • IPv4: 32 bit, 4 ottetti da 0 a 255
  • Classi A/B/C: si riconoscono dal primo ottetto (1-126 / 128-191 / 192-223)
  • Privati: 10.x.x.x, 172.16-31.x.x, 192.168.x.x — non instradati su Internet
  • Gateway: indirizzo IP del router locale; destinatario di tutti i pacchetti verso reti esterne
  • Subnet mask: 1 = bit di rete, 0 = bit di host; AND bit a bit con l'IP → indirizzo di rete
  • Indirizzo rete: host ID tutto a 0 — non assegnabile
  • Broadcast: host ID tutto a 1 — non assegnabile
  • FLSM: tutte le sottoreti uguali — semplice ma meno efficiente
  • VLSM: sottoreti su misura — parte sempre dalla più grande
ⓘ Un indirizzo IP/mask come 192.168.1.70/26 riassume tutto: l'IP dell'host è .70, la rete è .64, il broadcast è .127, il gateway sarà tipicamente .65 o .126.
