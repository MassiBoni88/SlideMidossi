Topologia di rete – Scenario Aziendale

Packet Tracer ⏱ 0:00 – 0:20

Un'azienda con tre edifici distinti deve connettere le proprie reti. Realizza la seguente topologia in Cisco Packet Tracer:

┌──────────────────────┐    ┌──────────────────────┐
│  Edificio A – Sede   │────│  Edificio B – Lab   │
│  Router_A             │    │  Router_B             │
└──────────┬───────────┘    └───────────┬──────────┘
          │  <── route statiche ──> │
          └────────────┬────────────┘
                     │   OSPF su tutti e 3
        ┌────────────────────────┐
        │  Edificio C – Magazzino│
        │  Router_C              │
        └────────────────────────┘
  • 🏢
    Edificio A – Sede: Uffici Amministrativi, Sala Riunioni, rete Wi-Fi ospiti. Almeno 3 sottoreti.
  • 🏭
    Edificio B – Laboratorio: PC tecnici, server interni, rete Wi-Fi personale. Almeno 2 sottoreti.
  • 🏗️
    Edificio C – Magazzino: terminali e dispositivi mobile dei magazzinieri. Almeno 2 sottoreti.
  • 🔗
    Link inter-router: collegamento punto-punto tra tutti e tre i router. Usa /30 per non sprecare indirizzi.
⚠ Spazio di indirizzamento: usa 172.20.0.0/16. Applica VLSM partendo dalle sottoreti con più host.

Configurazione IP e dispositivi (interfaccia grafica)

Packet Tracer ⏱ 0:20 – 0:50
  • 🖥️
    Assegna a ogni PC / Server indirizzo IP, subnet mask e default gateway tramite la scheda Desktop → IP Configuration.
  • 🌐
    Configura le interfacce dei router (IP + subnet mask) tramite Config → Interfaces. Tutte le porte devono essere attive.
  • 📡
    Configura ogni Access Point con un SSID descrittivo. Per le reti interne usa WPA-2 con passphrase; per la rete ospiti lascia la rete aperta (nessuna crittografia).
  • 📱
    Aggiungi i dispositivi wireless (tablet, smartphone, laptop) nelle reti appropriate e verificane la connettività di base.
⚠ Nota: la configurazione OSPF va eseguita esclusivamente via CLI nella sezione successiva. Tutto il resto tramite interfaccia grafica.
4

Routing: Statico (A ↔ B) e OSPF (tutti e 3)

Packet Tracer Google Doc ⏱ 0:50 – 1:10

4a – Route statiche tra Router_A e Router_B

Configura le route statiche esclusivamente sul link A ↔ B tramite Config → Routing → Static:

• Router_A: aggiungi una route per ogni sottorete di Edificio B (next-hop = IP di Router_B sul link A-B).
• Router_B: aggiungi una route per ogni sottorete di Edificio A (next-hop = IP di Router_A sul link A-B).

Non aggiungere route statiche verso Edificio C: sarà raggiunto tramite OSPF.
  • ✅
    Verifica con ping la raggiungibilità tra un PC di Edificio A e uno di Edificio B prima di proseguire.

4b – OSPF su tutti e tre i router (CLI)

  • ⌨️
    Accedi alla CLI di ogni router e configura OSPF:
    router ospf 1
    Dichiara tutte le reti direttamente connesse in area 0.
  • ⌨️
    Verifica con show ip ospf neighbor e show ip route.
    Incolla gli output nel Google Doc per ciascun router.
  • ✅
    Esegui un ping da un PC di Edificio A a uno di Edificio C per confermare il funzionamento di OSPF.
📝 Nel Google Doc: incolla i comandi OSPF usati su ogni router e gli output di show ip route e show ip ospf neighbor.

Domanda aperta

Google Doc ⏱ 1:10 – 1:40
OSPF e il modello ISO/OSI

OSPF utilizza TCP, UDP o nessuno dei due per scambiare i propri messaggi tra router? Motiva la risposta spiegando perché tale scelta è coerente con il funzionamento del protocollo e a quale livello del modello ISO/OSI opera OSPF.

Lunghezza consigliata: 6–10 righe. Usa un linguaggio tecnico preciso.
