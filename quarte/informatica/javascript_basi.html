Sintassi e Commenti

01 · 03/17

Struttura di Base

  • Le istruzioni terminano con ; (opzionale ma consigliato)
  • JavaScript è case-sensitive: nome ≠ Nome
  • Viene eseguito dal browser o da Node.js
  • Si inserisce in HTML con il tag <script>
💡 Posiziona il tag <script> prima di </body> per garantire che il DOM sia già caricato prima dell'esecuzione del codice.

Output

  • console.log() — stampa nella console del browser
  • alert() — finestra popup
  • document.write() — scrive nella pagina HTML
// Commento su una riga

/* Commento
   su più righe */

console.log("Ciao, mondo!");  // stampa
alert("Ciao!");             // popup

// JavaScript in HTML:
<script>
  console.log("eseguito!");
</script>

// Oppure file esterno:
<script src="script.js"></script>
🔍 Apri gli Strumenti per sviluppatori del browser (F12) e vai su Console per vedere l'output di console.log().

Variabili e Costanti

✅ Regola pratica: usa sempre const per default. Cambia in let solo se la variabile deve essere riassegnata. Evita var nel codice moderno.
⚠️ Hoisting: var viene "spostata" in cima alla funzione dal motore JS, ma inizializzata a undefined. let e const entrano in una Temporal Dead Zone e causano errore se usate prima della dichiarazione.

Tipi Primitivi vs Oggetti

  • Primitivi: number, string, boolean, null, undefined, symbol, bigint — immutabili, passati per valore
  • Oggetti: Object, Array, Function — passati per riferimento

Conversione di Tipo

Number("42")     // 42
String(42)       // "42"
Boolean(0)      // false
Boolean("")     // false
Boolean("ciao") // true
+"42"           // 42 (unario +)
⚠️ Attenzione alla coercizione implicita: "5" + 3 dà "53" (concatenazione), mentre "5" - 3 dà 2 (conversione automatica a numero).

Operatori

Aritmetici

a + b   // somma
a - b   // sottrazione
a * b   // moltiplicazione
a / b   // divisione
a % b   // modulo (resto)
a ** b  // potenza
a++     // incremento
a--     // decremento

Assegnazione

a  = 5
a += 3  // a = a + 3
a -= 2  // a = a - 2
a *= 4  // a = a * 4
a /= 2  // a = a / 2
a %= 3  // a = a % 3

Confronto

a == b   // uguale (con coercizione)
a === b  // strettamente uguale
a != b   // diverso
a !== b  // strettamente diverso
a < b    // minore
a > b    // maggiore
a <= b   // minore o uguale
a >= b   // maggiore o uguale
⚠️ Usa sempre === e !==: confrontano tipo E valore. == può dare risultati inaspettati ("5" == 5 è true).

Logici

a && b  // AND logico
a || b  // OR logico
!a      // NOT logico

// Short-circuit:
false && f() // f() non eseguita
true  || f() // f() non eseguita

// Nullish coalescing:
a ?? b  // b solo se a è null/undefined

Ternario

// condizione ? seVero : seFalso
let esito = voto >= 6
  ? "Promosso"
  : "Bocciato";

}

Valori "Falsy"

In JavaScript questi valori sono considerati falsi in un contesto booleano:

false
0
""   // stringa vuota
null
undefined
NaN

Tutto il resto è truthy (incluso "0" e []).

Esempio Pratico

let ora = new Date().getHours();
let saluto;

if (ora < 12) {
  saluto = "Buongiorno";
} else if (ora < 18) {
  saluto = "Buon pomeriggio";
} else {
  saluto = "Buonasera";
}
console.log(saluto);

Loop — while e do...while

04 · 08/17

while

Controlla la condizione prima di ogni iterazione. Il corpo può non essere mai eseguito.

let i = 0;
while (i < 5) {
  console.log("i = " + i);
  i++;
}
// Output: i = 0, i = 1, i = 2, i = 3, i = 4

// Esempio: somma fino a raggiungere 100
let somma = 0, n = 1;
while (somma < 100) {
  somma += n;
  n++;
}
console.log("Somma:", somma, "con n =", n);

do...while

Controlla la condizione dopo ogni iterazione. Il corpo viene eseguito almeno una volta.

let n = 0;
do {
  console.log("n = " + n);
  n++;
} while (n < 3);
// Output: n = 0, n = 1, n = 2

// Differenza chiave:
let x = 10;
while (x < 5) { console.log(x); } // non eseguito
do { console.log(x); } while (x < 5); // eseguito 1 volta
⚠️ Assicurati che la condizione diventi prima o poi false, altrimenti il loop è infinito e blocca la pagina.

Loop — for

04 · 09/17

for Classico

Struttura: for (init; condizione; aggiornamento)

// Conta da 0 a 4
for (let i = 0; i < 5; i++) {
  console.log(i);
}

// Scorre un array per indice
const voti = [6, 7, 8, 9];
for (let i = 0; i < voti.length; i++) {
  console.log("Voto " + i + ": " + voti[i]);
}

// break: esce dal loop
// continue: salta all'iterazione successiva
for (let i = 0; i < 10; i++) {
  if (i === 5) break;     // ferma a 4
  if (i % 2 === 0) continue; // salta pari
  console.log(i);          // 1, 3
}

for...of — su array e stringhe

Itera direttamente sui valori di un iterabile.

const frutti = ["mela", "pera", "uva"];
for (const frutto of frutti) {
  console.log(frutto);
}
// "mela"  "pera"  "uva"

// Su stringhe:
for (const c of "ciao") console.log(c);

for...in — su oggetti

Itera sulle chiavi (proprietà) di un oggetto.

const persona = { nome: "Ada", età: 18 };
for (const chiave in persona) {
  console.log(chiave + ": " + persona[chiave]);
}
// nome: Ada    età: 18

Funzioni

05 · 11/17 
// 1. Function declaration (hoistata)
function somma(a, b) {
  return a + b;
}
somma(3, 4); // 7

// 2. Function expression
const moltiplica = function(a, b) {
  return a * b;
};

// 3. Arrow function (ES6+)
const dividi = (a, b) => a / b;
const quadrato = n => n * n;  // un solo param
const saluta = () => "Ciao!"; // nessun param

// 4. Parametri di default
function benvenuto(nome = "Studente") {
  return `Ciao, ${nome}!`;
}
benvenuto();          // "Ciao, Studente!"
benvenuto("Luca");   // "Ciao, Luca!"

Parametri Rest e Spread

// Rest: raccoglie argomenti in array
function sommaMulti(...numeri) {
  return numeri.reduce((acc, n) => acc + n, 0);
}
sommaMulti(1, 2, 3, 4); // 10

// Spread: espande un array come argomenti
const nums = [3, 1, 4, 1, 5];
Math.max(...nums); // 5

Funzioni come Valori

In JS le funzioni sono oggetti di prima classe: si passano come argomenti (callback) e si restituiscono da altre funzioni.

const numeri = [3, 1, 4, 2];
numeri.sort((a, b) => a - b);  // [1,2,3,4]
numeri.filter(n => n > 2);    // [3,4]
numeri.map(n => n * 2);       // [6,2,8,4]

Oggetti

06 · 12/17 
// Oggetto letterale
let studente = {
  nome:   "Luca",
  voti:   [7, 8, 6],
  classe: "5A",
  saluta: function() {
    return "Ciao, sono " + this.nome;
  }
};

// Accesso alle proprietà
studente.nome;          // "Luca"  (dot notation)
studente["voti"];     // [7,8,6] (bracket notation)
studente.saluta();    // "Ciao, sono Luca"

// Aggiungere / modificare / eliminare
studente.media = 7;      // aggiunge
studente.nome = "Marco";  // modifica
delete studente.classe;   // elimina

// Verifica esistenza chiave
"nome" in studente;      // true

Destrutturazione

// Estrae proprietà in variabili
const { nome, voti } = studente;
console.log(nome);  // "Marco"

// Con rinomina e default
const { nome: n, media = 0 } = studente;

Array — Metodi Essenziali

const arr = [10, 20, 30];
arr.push(40);     // aggiunge in fondo
arr.pop();        // rimuove dall'ultimo
arr.unshift(0);  // aggiunge in testa
arr.shift();      // rimuove il primo
arr.length;       // 3
arr.includes(20); // true
arr.indexOf(30);  // 2
arr.slice(0,2);   // [10,20]
arr.join(", ");   // "10, 20, 30"
💡 this dentro un metodo di un oggetto letterale punta all'oggetto stesso. Nelle arrow function this non viene ridefinita (eredita dal contesto esterno).

Il DOM — Selezionare Elementi

06 · 13/17

Cos'è il DOM?

Il Document Object Model è la rappresentazione ad albero della pagina HTML in memoria. JavaScript può leggere e modificare il DOM per cambiare la pagina in modo dinamico, senza ricaricarla.

// Seleziona per ID (uno solo)
const titolo = document.getElementById("titolo");

// Seleziona col primo elemento che corrisponde
const card = document.querySelector(".card");
const p    = document.querySelector("p");
const btn  = document.querySelector("#mioBtn");

// Seleziona TUTTI gli elementi corrispondenti
const cards = document.querySelectorAll(".card");
// Restituisce una NodeList — usa forEach:
cards.forEach(el => console.log(el));

// Metodi storici (ancora usati)
document.getElementsByTagName("a");
document.getElementsByClassName("btn");

Struttura HTML di Esempio

<body>
  <h1 id="titolo">Ciao!</h1>
  <div class="card">Prima card</div>
  <div class="card">Seconda card</div>
  <button id="mioBtn">Clicca</button>
</body>

Il DOM — Modificare e Creare Elementi

06 · 14/17

Modificare Contenuto e Stile

const titolo = document.getElementById("titolo");

// Contenuto testuale (sicuro, no HTML)
titolo.textContent = "Nuovo titolo";

// Contenuto HTML (attenzione a XSS!)
titolo.innerHTML = "<strong>Grassetto</strong>";

// Proprietà dirette (preferibile)
titolo.className = "rosso";           // o meglio: classList
titolo.id;                              // "titolo"
// setAttribute solo per attributi non standard
titolo.setAttribute("data-indice", "3");
titolo.getAttribute("data-indice"); // "3"

// Stile inline
titolo.style.color = "red";
titolo.style.fontSize = "2rem";

// Classi CSS
titolo.classList.add("attivo");
titolo.classList.remove("nascosto");
titolo.classList.toggle("evidenziato");
titolo.classList.contains("attivo"); // true

Creare e Inserire Elementi

// 1. Crea un nuovo elemento
const div = document.createElement("div");
div.textContent = "Sono nuovo!";
div.classList.add("card");

// 2. Inserisci nel DOM
document.body.appendChild(div);          // in fondo
document.body.prepend(div);             // in testa
contenitore.insertBefore(div, riferim); // prima di

// 3. Rimuovere un elemento
div.remove();

// Esempio completo:
const lista = document.querySelector("ul");
["Mela", "Pera", "Uva"].forEach(frutto => {
  const li = document.createElement("li");
  li.textContent = frutto;
  lista.appendChild(li);
});
⚠️ Usa textContent invece di innerHTML quando inserisci testo fornito dall'utente, per evitare attacchi XSS (Cross-Site Scripting).

Il DOM — Eventi

06 · 15/17 
// Metodo 1: attributo HTML (sconsigliato)
<button onclick="saluta()">Clicca</button>

// Metodo 2: proprietà onclick (solo 1 handler)
const btn = document.getElementById("mioBtn");
btn.onclick = function() {
  alert("Cliccato!");
};

// Metodo 3: addEventListener (consigliato)
btn.addEventListener("click", function(e) {
  console.log("Target:", e.target);
  console.log("Tipo:", e.type);
});

// Rimuovere un listener
function handler() { console.log("once"); }
btn.addEventListener("click", handler);
btn.removeEventListener("click", handler);

Riepilogo — JavaScript Basi

Sintassi & Variabili

  • Le istruzioni terminano con ;, JS è case-sensitive
  • Usa const di default, let se serve riassegnare, evita var
  • let e const hanno scope di blocco ({ })

Tipi & Operatori

  • Tipi primitivi: number, string, boolean, null, undefined
  • Usa sempre === e !== per confrontare
  • Template literals: `Ciao ${nome}`

Controllo del Flusso

  • if/else if/else — rami condizionali
  • while — condizione prima; do...while — almeno una volta
  • for classico per indici; for...of per valori; for...in per chiavi

Funzioni & Oggetti

  • Tre modi: declaration, expression, arrow (=>)
  • Le funzioni sono first-class: si passano come callback
  • Oggetti con { }; accesso con . o [ ]; this nei metodi

DOM

  • getElementById, querySelector per selezionare
  • textContent, innerHTML, style, classList per modificare
  • createElement + appendChild per creare nodi

Eventi

  • addEventListener è il metodo consigliato (può avere più handler)
  • L'oggetto event contiene info sull'evento (target, type…)
  • preventDefault() blocca il comportamento nativo (es. submit)
