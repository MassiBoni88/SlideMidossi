A cosa servono i puntatori?

MOTIVAZIONE
💡 L'idea in una frase: un puntatore permette di riferirsi a un dato senza copiarlo. Invece del dato, si passa il suo indirizzo.
1

Modificare le variabili di chi chiama

Una funzione riceve copie dei parametri. Con l'indirizzo lavora sugli originali e può «restituire» più risultati. scambia(&x, &y);

2

Non copiare dati grandi

Passare l'indirizzo di una struct o di un array costa sempre 8 byte, qualunque sia la loro dimensione. promuovi(&studente);

3

Usare memoria creata durante l'esecuzione

new crea i dati quando servono e restituisce solo un indirizzo: il puntatore è l'unico modo per raggiungerli. int* v = new int[n];

4

Collegare i dati tra loro

Liste, alberi, grafi, una playlist: ogni elemento sa dov'è il successivo. Senza puntatori queste strutture non si costruiscono. Nodo* next;

Un'analogia: allegato o link?

  • 📎 Allegato = una copia: se il destinatario la modifica, il vostro originale non cambia. È il passaggio per valore.
  • 🔗 Link a un Google Doc = un puntatore: tutti lavorano sullo stesso documento, e il link è piccolo anche se il documento è enorme.
  • Documento cancellato ma link ancora salvato: il link non porta più a niente. È il dangling pointer.
ⓘ Ci sono anche dove non si vedono. vector, string e list li usano al loro interno. In Java e in Python ogni variabile che contiene un oggetto è, di fatto, un puntatore nascosto. Sistemi operativi, driver e microcontrollori come Arduino lavorano direttamente con gli indirizzi.

Ogni variabile ha un indirizzo

SEZIONE 01

La RAM: una fila di celle numerate

La memoria è una fila di celle da 1 byte = 8 bit, ognuna con un numero: il suo indirizzo. Una variabile occupa tante celle consecutive quante ne richiede il suo tipo. Tipo, nome e valore li conoscete già: la novità di oggi è l'indirizzo.

int eta = 17;
double media = 7.5;
cout << eta;             // 17          (il valore)
cout << &eta;            // 0x16fdff2ac (l'indirizzo)
cout << sizeof(eta);     // 4           (byte occupati = 32 bit)
cout << sizeof(double);  // 8           (sizeof accetta anche un tipo)

Il puntatore

SEZIONE 02

Una variabile che contiene un indirizzo

Un puntatore è una variabile il cui valore è un indirizzo di memoria. Se p contiene l'indirizzo di eta, diciamo che p punta a eta.

int eta = 17;
int* p = &eta;    // p contiene l'indirizzo di eta

cout << p;        // 0x1000 → l'indirizzo
cout << *p;       // 17     → il valore puntato

ⓘ int* p, int *p e int * p sono identici. Nelle slide scriviamo int* p: l'asterisco fa parte del tipo «puntatore a int».

La trappola della dichiarazione multipla

int* a, b;     // ATTENZIONE: a è int*, b è un int!

int *c, *d;    // corretto: due puntatori
int* e;        // ancora meglio:
int* f;        // un puntatore per riga

I tipi devono corrispondere

int x = 5;
double y = 2.5;
int* p = &x;    // ok
p = &y;         // ERRORE: &y è un double*, non un int*
int* q = x;     // ERRORE: x è un numero, non un indirizzo
⚠ Nella dichiarazione l'asterisco vale solo per la variabile che lo segue: int* a, b; crea un puntatore e un intero.

nullptr: il puntatore che non punta a niente

SEZIONE 02

Un puntatore non inizializzato è un pericolo

Come ogni variabile locale, un puntatore appena dichiarato contiene un valore casuale, cioè un indirizzo qualsiasi. Usarlo significa leggere o scrivere in una zona di memoria a caso.

int* p;             // indirizzo casuale
*p = 5;             // scrive chissà dove → crash

int* q = nullptr;   // «non punta a niente»
if (q != nullptr) {
    cout << *q;     // eseguito solo se q punta a qualcosa
}
ⓘ Nei programmi più vecchi trovate NULL o 0. Nel C++ moderno si usa nullptr.

Le regole d'oro

  1. Inizializzate ogni puntatore appena lo dichiarate: con un indirizzo (&x) oppure con nullptr.
  2. Prima di usare *p, controllate che p != nullptr.
  3. Non dereferenziate mai un puntatore se non sapete dove punta.

Segmentation fault

Se il programma prova ad accedere a memoria che non gli appartiene, il sistema operativo lo blocca. È l'errore tipico dei puntatori:

  • Linux / macOS: Segmentation fault (codice 139)
  • Windows / Code::Blocks: Process returned -1073741819 (0xC0000005)
⚠ Il compilatore spesso non si accorge di questi errori: di solito si scoprono solo eseguendo il programma. Compilate con -Wall per avere più avvisi.

Verifica lampo: carta e penna

VERIFICA

① Disegna la memoria

int x = 4, y = 6;
int* p = &x;
int* q = &y;
*q = *p;
p = q;
*p = 10;

Alla fine quanto valgono x e y? Dove puntano p e q?

x = 4, y = 10, e p e q puntano entrambi a y. *q = *p copia il valore 4 in y, p = q copia l'indirizzo, *p = 10 scrive in y.

② Cosa stampa?

int n = 3;
int* p = &n;
int* q = p;
*q = *q * 2;
cout << n << " " << *p;

Attenzione alla terza riga: che cosa viene copiato?

Stampa 6 6. q = p copia l'indirizzo, quindi p e q puntano entrambi a n: modificare *q modifica n, e quindi anche *p.

③ Trova l'errore

int* p;
int k = 8;
*p = k;
cout << *p;

Il programma compila. Cosa succede quando lo eseguiamo? Come si corregge?

p non è inizializzato: *p = k scrive a un indirizzo casuale e può far crashare il programma. Correzione: int* p = &k;. Attenzione: p = &k e *p = k sono due cose diverse!

Funzioni: lo scambio che non funziona

SEZIONE 03 
void scambia(int a, int b) {
    int t = a;
    a = b;
    b = t;
}

int main() {
    int x = 1, y = 2;
    scambia(x, y);
    cout << x << " " << y;    // 1 2 → non scambiati!
}

Passaggio per valore

Quando chiamate scambia(x, y), la funzione riceve delle copie di x e y, cioè a e b. Scambia le copie, che spariscono quando la funzione termina: x e y del main restano come prima.

Funzioni: passaggio per indirizzo

SEZIONE 03 
void scambia(int* a, int* b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main() {
    int x = 1, y = 2;
    scambia(&x, &y);          // passo gli INDIRIZZI
    cout << x << " " << y;    // 2 1 ✓
}

Cosa succede

La funzione riceve una copia degli indirizzi di x e y. Ma anche una copia dell'indirizzo porta alla variabile originale: tramite *a e *b la funzione legge e scrive proprio x e y del main.

La ricetta

  • nel prototipo il parametro è un puntatore: int* a
  • nella chiamata si passa l'indirizzo: scambia(&x, &y)
  • nel corpo si usa il valore puntato: *a
✓ Uso tipico: funzioni che devono «restituire» più risultati. Ad esempio void divisione(int a, int b, int* q, int* r) calcola quoziente e resto.

SEZIONE 03

Il nome dell'array è un indirizzo

Gli elementi di un array occupano celle consecutive. Il nome dell'array usato da solo vale l'indirizzo del primo elemento: v equivale a &v[0].

Aritmetica dei puntatori

p + 1 non aggiunge 1 byte, ma un elemento: per un int* avanza di 4 byte (sizeof(int)), per un double* di 8.

✓ Ecco cosa c'era sotto: v[i] è solo un modo comodo di scrivere *(v + i). Le parentesi quadre calcolano un indirizzo e leggono il valore che si trova lì.
⚠ Il C++ non controlla i limiti: su un array di 5 elementi, *(p + 10) o v[10] leggono memoria che non è vostra. Non c'è nessun errore di compilazione, solo valori strani o un crash.

Array e funzioni: ecco perché si modificano

SEZIONE 03 
void azzera(int v[], int n) {   // int v[] è in realtà int* v
    for (int i = 0; i < n; i++)
        v[i] = 0;
}

int main() {
    int dati[3] = {7, 8, 9};
    azzera(dati, 3);
    cout << dati[0];   // 0 → l'array originale è cambiato
}

L'array non viene copiato

Quando passate un array a una funzione, la funzione riceve l'indirizzo del primo elemento. Per questo lavora direttamente sull'array originale, e per questo ha sempre bisogno anche della dimensione n.

Due scritture, stesso significato

void azzera(int v[], int n);   // forma «da array»
void azzera(int* v, int n);    // forma «da puntatore»

Il compilatore le tratta in modo identico: in entrambi i casi il parametro v è un int*.

⚠ Dentro la funzione sizeof(v) dà la dimensione del puntatore (8 byte su un sistema a 64 bit), non quella dell'array: la funzione non può sapere quanti elementi ci sono. Ecco perché si passa n.
ⓘ Le matrici funzionano allo stesso modo: sono memorizzate riga dopo riga, in celle consecutive. Per questo, quando si passa una matrice a una funzione, va indicato il numero di colonne (int m[][4]): serve per calcolare dove inizia ogni riga.

Puntatori a struct e operatore ->

SEZIONE 03 
struct Studente {
    string nome;
    int voto;
};

Studente s = {"Luca", 7};
Studente* p = &s;

(*p).voto = 8;     // forma lunga: parentesi obbligatorie
p->voto = 8;       // forma breve: identica
cout << p->nome;   // Luca

Punto o freccia?

Se avete…
usate…
Studente s;
s.voto
Studente* p;
p->voto
void promuovi(Studente* st) {
    if (st->voto < 6)
        st->voto = 6;
}

// nel main
promuovi(&s);

Perché passare l'indirizzo di una struct?

  • La funzione può modificare la struct originale.
  • Non si copia tutta la struct, che può essere grande (stringhe, array…).
⚠ *p.voto non funziona: il punto ha priorità più alta dell'asterisco, quindi il compilatore lo legge come *(p.voto). Servono le parentesi o, meglio, la freccia.
➜ La freccia -> sarà lo strumento principale quando costruiremo le liste.

Esercizio 4: più risultati da una sola funzione

LAB 1 · ★★

Consegna

  1. void minMax(int v[], int n, int* min, int* max): calcola il minimo e il massimo dell'array.
  2. void divisione(int a, int b, int* q, int* r): calcola quoziente e resto della divisione intera.
  3. bool statistiche(int voti[], int n, double* media, int* insufficienti): calcola la media e il numero di voti sotto il 6. Restituisce false se n vale 0, perché non c'è niente da calcolare.
⚠ Per incrementare il valore puntato servono le parentesi: (*insufficienti)++. Scrivendo *insufficienti++ si incrementa il puntatore, non il valore!
✓ Output atteso: Minimo 4, Massimo 9 · 17 / 5 = 3 resto 2 · Media 6.5, Insufficienti 2. 
#include <iostream>
using namespace std;

// TODO: scrivi minMax, divisione, statistiche

int main() {
    int voti[6] = {7, 4, 9, 5, 6, 8};

    int mi, ma;
    minMax(voti, 6, &mi, &ma);
    cout << "Minimo: " << mi << "  Massimo: " << ma << endl;

    int q, r;
    divisione(17, 5, &q, &r);
    cout << "17 / 5 = " << q << " resto " << r << endl;

    double media;
    int ins;
    if (statistiche(voti, 6, &media, &ins))
        cout << "Media: " << media << "  Insufficienti: " << ins << endl;

I limiti dell'array

  • Inserire o cancellare in mezzo obbliga a spostare tutti gli elementi successivi: con un milione di elementi, fino a un milione di spostamenti.
  • La dimensione è fissa e va decisa prima. Se è troppo grande si spreca memoria, se è troppo piccola non basta.
💡 E se ogni elemento sapesse semplicemente dov'è il successivo? Allora non servirebbe più tenerli in fila uno dopo l'altro.
➜ È l'idea della lista concatenata. La proviamo subito con strumenti che conoscete già: array e struct.

Il limite che resta

L'array ha comunque 6 celle: quando quelle libere finiscono, la lista non può più crescere.

Ci serve un modo per creare celle nuove mentre il programma è in esecuzione.

➜ In C++ questo si fa con new: è la memoria dinamica.

Memoria dinamica: new e delete

SEZIONE 05

Chiedere memoria durante l'esecuzione

new riserva memoria in una zona chiamata heap e restituisce il suo indirizzo. Quella memoria non ha un nome: si raggiunge solo con il puntatore, e resta occupata finché non la restituite con delete.

int* p = new int;      // spazio per un int nello heap
*p = 42;               // lo uso tramite il puntatore
cout << *p;            // 42
delete p;              // restituisco la memoria
p = nullptr;

int n;
cin >> n;
int* v = new int[n];   // array grande quanto serve, deciso ORA
v[0] = 5;              // si usa come un array normale
delete[] v;            // con new[] si usa delete[]

Le regole d'oro

  • A ogni new deve corrispondere un delete.
  • A new[] corrisponde delete[], con le parentesi.
  • Dopo delete, rimettete il puntatore a nullptr.
🔑 È la chiave delle liste: un nodo creato con new dentro una funzione continua a esistere anche dopo che la funzione è terminata.

Due errori da evitare

SEZIONE 05

Memory leak

Memoria allocata e mai restituita, perché si è perso l'unico puntatore che la raggiungeva.

int* p = new int(5);
p = new int(9);     // il primo indirizzo è perso:
                    // quella memoria resta occupata
                    // e nessuno può più liberarla

// corretto
int* q = new int(5);
delete q;           // prima restituisco
q = new int(9);
delete q;
⚠ In un esercizio non ve ne accorgete. In un programma che resta acceso per giorni, come un server o un videogioco, un leak dentro un ciclo consuma tutta la RAM.

Dangling pointer

Il problema opposto: il puntatore esiste ancora, ma la memoria a cui punta è già stata restituita.

int* p = new int(5);
delete p;           // memoria restituita
cout << *p;         // ERRORE: memoria non più valida

// corretto
delete p;
p = nullptr;        // dopo delete azzero sempre
if (p != nullptr)
    cout << *p;
✗ Anche fare delete due volte sullo stesso indirizzo è un errore grave. delete su nullptr invece è innocuo: un motivo in più per azzerare.

Ogni funzione che può cambiare il primo nodo restituisce la nuova testa, e nel main si scrive sempre testa = funzione(testa, …);

Inserimento in coda

SEZIONE 06 
Nodo* inserisciInCoda(Nodo* testa, int x) {
    Nodo* nuovo = new Nodo;
    nuovo->dato = x;
    nuovo->next = nullptr;        // sarà l'ultimo

    if (testa == nullptr)         // lista vuota:
        return nuovo;             // il nuovo nodo è anche la testa

    Nodo* p = testa;
    while (p->next != nullptr)    // mi fermo sull'ULTIMO nodo
        p = p->next;
    p->next = nuovo;              // aggancio in fondo
    return testa;                 // la testa non cambia
}

Due differenze rispetto alla stampa

  • La condizione è p->next != nullptr: ci fermiamo sull'ultimo nodo, non dopo.
  • La lista vuota è un caso speciale: se testa è nullptr, p->next farebbe crashare il programma. In quel caso il nuovo nodo diventa la testa.

Eliminare: la testa e l'intera lista

Nodo* eliminaTesta(Nodo* testa) {
    if (testa == nullptr)

    testa = testa->next;         // la testa avanza

    return testa;
}

Nodo* svuota(Nodo* testa) {
    while (testa != nullptr)
        testa = eliminaTesta(testa);
    return nullptr;

    } while (scelta != 0);

}

bool cerca(Nodo* testa, int x) {

        if (p->dato == x) return true;

Nodo* inserisciInCoda(Nodo* testa, int x) {
    Nodo* nuovo = new Nodo;
    nuovo->dato = x;
    nuovo->next = nullptr;
    if (testa == nullptr)
        return nuovo;
    Nodo* p = testa;
    while (p->next != nullptr)
        p = p->next;
    p->next = nuovo;

Nodo* eliminaTesta(Nodo* testa) {

    Nodo* vecchia = testa;
    testa = testa->next;

    return testa;
}

// A · Elimina un valore
Nodo* eliminaValore(Nodo* testa, int x) {
    if (testa == nullptr) return nullptr;
    if (testa->dato == x)
        return eliminaTesta(testa);

    Nodo* prec = testa;
    while (prec->next != nullptr && prec->next->dato != x)
        prec = prec->next;

    if (prec->next != nullptr) {        // trovato: è prec->next
        Nodo* daCancellare = prec->next;
        prec->next = daCancellare->next;
        delete daCancellare;
    }
    return testa;
}

// B · Lista ordinata
Nodo* inserisciOrdinato(Nodo* testa, int x) {
    if (testa == nullptr || x <= testa->dato)
        return inserisciInTesta(testa, x);

    Nodo* prec = testa;
    while (prec->next != nullptr && prec->next->dato < x)
        prec = prec->next;

    Nodo* nuovo = new Nodo;
    nuovo->dato = x;
    nuovo->next = prec->next;
    prec->next = nuovo;
    return testa;
}
// C · Playlist
Brano* aggiungiBrano(Brano* testa, string titolo, int durata) {
    Brano* nuovo = new Brano;
    nuovo->titolo = titolo;
    nuovo->durata = durata;
    nuovo->next = nullptr;
    if (testa == nullptr) return nuovo;
    Brano* p = testa;
    while (p->next != nullptr) p = p->next;
    p->next = nuovo;
    return testa;
}

void stampaPlaylist(Brano* testa) {
    int totale = 0;
    int n = 1;
    for (Brano* p = testa; p != nullptr; p = p->next) {
        cout << n << ". " << p->titolo << " (" << p->durata / 60 << ":"
             << (p->durata % 60 < 10 ? "0" : "") << p->durata % 60 << ")" << endl;
        totale += p->durata;
        n++;
    }
    cout << "Durata totale: " << totale / 60 << " min "
         << totale % 60 << " s" << endl;
}
