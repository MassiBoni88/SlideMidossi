Il primo programma in Python

SEZIONE 00

Caratteristiche di Python

Linguaggio interpretato, ad alto livello, con sintassi pulita. Non servono parentesi graffe: i blocchi si definiscono con l'indentazione (di solito 4 spazi).

Stampare a video

La funzione print() visualizza un messaggio sullo schermo. Va a capo automaticamente al termine.

ⓘI commenti iniziano con # e arrivano fino a fine riga. Servono a spiegare il codice, non vengono eseguiti.
# Il classico "Hello, world!"
print("Ciao, mondo!")

# Più valori separati da virgola
print("Somma:", 3 + 4)
# Output: Somma: 7

# Cambiare il separatore
print("A", "B", "C", sep="-")
# Output: A-B-C

# Evitare di andare a capo
print("Ciao ", end="")
print("mondo")
# Output: Ciao mondo

Variabili e tipi di dato

SEZIONE 01

Tipizzazione dinamica

Una variabile si crea semplicemente assegnando un valore con =. Python ne deduce il tipo da solo e può cambiarlo a runtime.

# Assegnazione semplice
nome = "Marco"      # str (stringa)
eta = 17             # int (intero)
altezza = 1.78      # float (decimale)
maggiorenne = False  # bool (True/False)

# Assegnazione multipla
x, y, z = 1, 2, 3

# Conoscere il tipo
print(type(eta))      # <class 'int'>
print(type(altezza))  # <class 'float'>

Regole per i nomi

  • iniziano con lettera o _
  • solo lettere, cifre, underscore
  • case-sensitive: Eta ≠ eta
  • nomi parlanti: media_voti e non x
  • evita parole chiave (if, for, …)

Input dall'utente e conversioni

SEZIONE 02

La funzione input()

Legge dalla tastiera e restituisce sempre una stringa. Per usarla come numero serve la conversione (cast) con int() o float().

# input() restituisce SEMPRE str
nome = input("Come ti chiami? ")
print("Ciao", nome)

# Per i numeri serve il cast
eta = int(input("Età: "))
prezzo = float(input("Prezzo: "))

print("Tra 10 anni avrai", eta + 10)
⚠Errore tipico: dimenticare int(). Se eta = input(...) e poi eta + 10, Python prova a concatenare stringa e numero e va in errore.

Stringhe e f-string

SEZIONE 03

Creare e combinare stringhe

Le stringhe si scrivono tra apici singoli o doppi. Si possono unire con + e ripetere con *.

# Apici singoli o doppi: equivalenti
s1 = 'Ciao'
s2 = "mondo"

# Concatenazione
saluto = s1 + " " + s2
print(saluto)        # Ciao mondo

# Ripetizione
print("-" * 10)     # ----------

# Lunghezza
print(len(saluto))   # 10

# Indicizzazione (da 0)
print(saluto[0])      # C
print(saluto[-1])     # o (ultimo)

f-string: inserire variabili nel testo

Prefissando una stringa con f si possono inserire variabili ed espressioni tra { }. È il modo moderno e leggibile.

nome = "Anna"
eta = 16

# Classica (con +): scomodo, serve str()
print("Ciao " + nome + ", " + str(eta))

# Con f-string: pulita
print(f"Ciao {nome}, hai {eta} anni")

# Espressioni dentro {}
print(f"Tra 5 anni: {eta + 5}")

# Formattazione decimali
pi = 3.14159
print(f"Pi greco: {pi:.2f}")
# Pi greco: 3.14
✓Le f-string sono il metodo consigliato: scrivi il testo come lo vedrai e metti tra graffe le parti variabili.

L'istruzione if / elif / else

SEZIONE 04

Come funziona

Il blocco indentato sotto if viene eseguito solo se la condizione è True. Con elif si gestiscono più casi a cascata, con else il caso rimanente.

# Sintassi base
if condizione:
    # eseguito se True

# if ... else
if condizione:
    # ramo vero
else:
    # ramo falso

# if ... elif ... else
if voto >= 9:
    print("Ottimo")
elif voto >= 6:
    print("Sufficiente")
else:
    print("Insufficiente")
# Programma completo
eta = int(input("Età: "))

if eta >= 18:
    print("Maggiorenne")
else:
    print("Minorenne")

voto = int(input("Voto: "))

if voto >= 9:
    print("Ottimo")
elif voto >= 7:
    print("Buono")
elif voto >= 6:
    print("Sufficiente")
else:
    print("Insufficiente")
⚠Non dimenticare i due punti : alla fine della riga if, elif, else. E indenta il corpo (4 spazi).

if annidati e operatore ternario

SEZIONE 04

if annidati

Un if può contenerne un altro al suo interno. Ogni livello aggiunge una indentazione.

x = 15

if x > 0:
    print("Positivo")

    if x % 2 == 0:
        print("e pari")
    else:
        print("e dispari")
else:
    print("Non positivo")

# Output: Positivo  e dispari
ⓘSpesso un if annidato si può riscrivere combinando le condizioni con and per migliorare la leggibilità.

Operatore ternario

Forma compatta di if-else su una riga. Restituisce uno dei due valori in base alla condizione.

# Sintassi
variabile = val_vero if condizione else val_falso

# Esempio
a, b = 10, 20

# Con if-else classico
if a > b:
    massimo = a
else:
    massimo = b

# Con ternario (equivalente)
massimo2 = a if a > b else b

print(massimo2)   # 20

# Anche dentro un print
n = 7
print("pari" if n % 2 == 0 else "dispari")
ⓘUsa il ternario solo per espressioni semplici. Per logica complessa preferisci if-else.

Il ciclo while

SEZIONE 05

Ripeti finché la condizione è vera

Il ciclo while valuta la condizione prima di eseguire il corpo. Se è subito False, il corpo non viene mai eseguito.

# Sintassi
while condizione:
    # corpo
    # aggiorna la variabile!

# Conta da 1 a 5
i = 1
while i <= 5:
    print(i, end=" ")
    i += 1
# Output: 1 2 3 4 5
⚠Loop infinito: se dimentichi di aggiornare la variabile di controllo, la condizione rimane sempre True e il programma si blocca. Interrompi con Ctrl+C.
# Somma numeri finché input != 0
somma = 0
n = int(input("Numero (0 per uscire): "))

while n != 0:
    somma += n
    n = int(input("Numero (0 per uscire): "))

print(f"Somma: {somma}")


# Validazione input
voto = -1
while voto < 0 or voto > 10:
    voto = int(input("Voto (0-10): "))
    if voto < 0 or voto > 10:
        print("Non valido!")

print(f"Accettato: {voto}")
✓Usa while quando il numero di iterazioni non è noto a priori: dipende da un input o da un evento.

Il ciclo for con range()

SEZIONE 06

Iterare un numero noto di volte

In Python il for non è un ciclo a contatore puro: itera su una sequenza. Con range() generiamo la sequenza di numeri voluta.

# range(stop): da 0 a stop-1
for i in range(5):
    print(i, end=" ")
# Output: 0 1 2 3 4

# range(start, stop): da start a stop-1
for i in range(1, 6):
    print(i, end=" ")
# Output: 1 2 3 4 5

# range(start, stop, step)
for i in range(0, 10, 2):
    print(i, end=" ")
# Output: 0 2 4 6 8

# Conto alla rovescia
for i in range(5, 0, -1):
    print(i, end=" ")
# Output: 5 4 3 2 1
# Tavola del 7
for i in range(1, 11):
    print(f"7 x {i} = {7*i}")


# For annidati: matrice 3x3
for r in range(1, 4):
    for c in range(1, 4):
        print(r*c, end="\t")
    print()


# Somma dei primi 100 numeri
somma = 0
for i in range(1, 101):
    somma += i
print(f"Totale: {somma}")
# Totale: 5050
ⓘRicorda: range(n) arriva fino a n-1, escluso. Per contare da 1 a 10 serve range(1, 11).

for su stringhe e liste · confronto cicli

SEZIONE 06

Iterare direttamente sugli elementi

Il for di Python scorre gli elementi di una sequenza, non i suoi indici. Niente i = 0; i++.

# Iterare una stringa
parola = "Ciao"
for c in parola:
    print(c, end="-")
# Output: C-i-a-o-

# Iterare una lista
numeri = [10, 20, 30, 40]
for n in numeri:
    print(n, end=" ")
# Output: 10 20 30 40

# Con indice + valore: enumerate()
for i, n in enumerate(numeri):
    print(f"pos {i}: {n}")

# Esempio: parole più lunghe di 4 lettere
parole = ["sole", "mare", "montagna", "cielo"]
for p in parole:
    if len(p) > 4:
        print(p)
# Output: montagna  cielo

break e continue

SEZIONE 07

break — interrompe il ciclo

break termina immediatamente il ciclo più interno e passa all'istruzione successiva.

# Esce quando trova 5
for i in range(1, 11):
    if i == 5:
        break
    print(i, end=" ")
# Output: 1 2 3 4


# Cerca il primo pari maggiore di 7
n = 8
while True:
    if n % 2 == 0 and n > 7:
        break
    n += 1
print(f"Trovato: {n}")
# Output: Trovato: 8

continue — salta l'iterazione

continue salta il resto del corpo per l'iterazione corrente e passa direttamente alla successiva.

# Stampa solo i dispari
for i in range(1, 11):
    if i % 2 == 0:
        continue
    print(i, end=" ")
# Output: 1 3 5 7 9
