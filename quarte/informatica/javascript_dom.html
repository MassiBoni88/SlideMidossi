Struttura del DOM

01 · 3/12

Il DOM come Albero

Quando il browser carica una pagina HTML la converte in un albero di nodi in memoria. JavaScript accede a questo albero tramite l'oggetto globale document.

Tipi di Nodo principali

  • Element — un tag HTML (<div>, <p>…)
  • Text — il testo dentro un elemento
  • Document — la radice dell'intero albero
  • Comment — i commenti HTML
💡 In pratica si lavora quasi sempre con i nodi di tipo Element. I metodi come querySelector restituiscono solo elementi, non nodi di testo.

HTML di esempio

<html>
  <head>
    <title>Pagina</title>
  </head>
  <body>
    <h1 id="titolo">Ciao!</h1>
    <ul id="lista">
      <li>Primo</li>
      <li>Secondo</li>
    </ul>
  </body>
</html>

ulbodyli, li

Selezionare Elementi

02 · 4/12

Metodi di Selezione

// Per ID — restituisce 1 elemento o null
const titolo = document.getElementById("titolo");

// CSS selector — restituisce il 1° trovato
const card    = document.querySelector(".card");
const primoLi = document.querySelector("ul li");
const btn     = document.querySelector("#mioBtn");

// CSS selector — restituisce tutti (NodeList)
const voci = document.querySelectorAll("li");
voci.forEach(li => console.log(li.textContent));

// Cercare dentro un elemento specifico
const nav  = document.querySelector("nav");
const link = nav.querySelector("a.attivo");
MetodoRitornaAggiornata?
getElementByIdElement | null—
querySelectorElement | null—
querySelectorAllNodeList staticaNo
getElementsByClassNameHTMLCollectionSì
getElementsByTagNameHTMLCollectionSì
💡 Preferisci sempre querySelector e querySelectorAll: accettano qualsiasi selettore CSS, sono coerenti tra loro e restituiscono tipi prevedibili.
⚠️ HTMLCollection è live: se aggiungi o rimuovi elementi il DOM, la collezione cambia automaticamente, il che può causare loop infiniti.

Proprietà Dirette vs Attributi

03 · 5/12

Proprietà dirette — il modo corretto

Gli attributi HTML standard hanno una corrispondente proprietà JavaScript sull'oggetto Element. Usare la proprietà è più veloce, type-safe e idiomatico.

const el = document.querySelector("h1");

// id
el.id = "nuovo-id";
console.log(el.id);           // "nuovo-id"

// class → className (una stringa)
el.className = "titolo rosso";

// class → classList (oggetto, più comodo)
el.classList.add("evidenziato");
el.classList.remove("rosso");
el.classList.toggle("attivo");
el.classList.contains("titolo"); // true

// href, src, value…
document.querySelector("a").href  = "https://esempio.it";
document.querySelector("img").src  = "foto.png";
document.querySelector("input").value = "ciao";

setAttribute — solo quando serve

setAttribute converte sempre il valore in stringa e bypassa la proprietà JS. Usalo solo per attributi non standard.

// ✅ Usa setAttribute per data-* e aria-*
el.setAttribute("data-indice", "3");
el.getAttribute("data-indice");  // "3"

// Oppure con dataset (più moderno)
el.dataset.indice = "3";
el.dataset.indice;                  // "3"

// Attributi ARIA per accessibilità
el.setAttribute("aria-label", "Chiudi");
el.setAttribute("aria-expanded", "true");

// ❌ Evita così per class e id:
// el.setAttribute("class", "rosso"); // usa className/classList
// el.getAttribute("id");             // usa el.id
✅ Regola pratica: se l'attributo ha un corrispettivo nel DOM (id, class, href, value…), usa la proprietà. Usa setAttribute solo per data-* e aria-*.

Modificare Contenuto e Stile

03 · 6/12

Contenuto Testuale e HTML

const p = document.querySelector("p");

// textContent — solo testo, sicuro
p.textContent = "Testo aggiornato";
console.log(p.textContent); // "Testo aggiornato"

// innerHTML — può contenere tag HTML
p.innerHTML = "<strong>Grassetto</strong> e normale";

// ⚠️ Mai usare innerHTML con input dell'utente!
// const nome = utente.input;         // potrebbe contenere <script>
// p.innerHTML = nome;                // XSS — pericoloso!
// p.textContent = nome;              // ✅ sicuro

// innerText — come textContent ma rispetta il CSS
// (elemento hidden con display:none → restituisce "")
p.innerText = "Testo visibile";
⚠️ Usa textContent ogni volta che inserisci testo fornito dall'utente. innerHTML interpreta i tag e apre la porta agli attacchi XSS.

Stile Inline e Classi CSS

const box = document.querySelector(".box");

// Stile inline (proprietà camelCase)
box.style.color       = "#2563eb";
box.style.fontSize    = "1.2rem";
box.style.marginTop   = "16px";
box.style.display     = "none";   // nasconde
box.style.display     = "";       // ripristina

// classList — gestione classi CSS
box.classList.add("attivo", "grande"); // più classi
box.classList.remove("nascosto");
box.classList.toggle("selezionato");
box.classList.replace("rosso", "verde");
box.classList.contains("attivo"); // true/false
💡 Preferisci classList allo stile inline: tiene la logica nel CSS e il JS diventa più leggibile. Lo stile inline ha priorità massima e sovrascrive tutto.

Creare Nuovi Elementi

04 · 7/12

createElement — il metodo base

// 1. Crea l'elemento (non è ancora nel DOM)
const div = document.createElement("div");

// 2. Configura le proprietà
div.id          = "mioDiv";
div.className   = "card attivo";
div.textContent = "Sono un nuovo div";

// 3. Aggiungi stile o attributi
div.style.color = "var(--accent1)";
div.setAttribute("data-id", "42");

// Creare un link completo
const a   = document.createElement("a");
a.href      = "https://esempio.it";
a.textContent = "Vai al sito";
a.target    = "_blank";

// Creare un'immagine
const img = document.createElement("img");
img.src = "foto.png";
img.alt = "Descrizione";

Struttura annidata

Si possono creare alberi interi prima di inserirli nel DOM.

// Costruire una card complessa
const card  = document.createElement("div");
card.className = "card";

const titolo = document.createElement("h3");
titolo.textContent = "Titolo Card";

const testo = document.createElement("p");
testo.textContent = "Descrizione della card.";

// Annida: prima titolo poi testo dentro card
card.appendChild(titolo);
card.appendChild(testo);

// Adesso card contiene: <div class="card">
//   <h3>Titolo Card</h3>
//   <p>Descrizione della card.</p>
// </div>
⚡ Costruisci la struttura completa prima di inserirla nel DOM: ogni modifica al DOM causa un reflow (ricalcolo del layout). Meno inserimenti = pagina più veloce.

Inserire Elementi nel DOM

04 · 8/12

I metodi di inserimento

const lista = document.querySelector("ul");
const li    = document.createElement("li");
li.textContent = "Nuovo elemento";

// In fondo ai figli
lista.appendChild(li);

// In testa ai figli
lista.prepend(li);

// Prima di un elemento di riferimento
const terzo = lista.querySelector("li:nth-child(3)");
lista.insertBefore(li, terzo);

// Posizione precisa con insertAdjacentElement
// "beforebegin" | "afterbegin" | "beforeend" | "afterend"
terzo.insertAdjacentElement("afterend", li);

// Sostituire un figlio
lista.replaceChild(li, terzo);     // (nuovo, vecchio)
terzo.replaceWith(li);              // forma moderna

insertAdjacentElement — posizioni

PosizioneDove inserisce
beforebeginPrima del tag di apertura (fratello precedente)
afterbeginSubito dopo il tag di apertura (primo figlio)
beforeendSubito prima del tag di chiusura (ultimo figlio)
afterendDopo il tag di chiusura (fratello successivo)
💡 append() è la versione moderna di appendChild(): accetta anche stringhe di testo e può ricevere più argomenti contemporaneamente.
lista.append(li1, li2, "testo")

Rimuovere e Sostituire Elementi

05 · 9/12

Rimuovere un Elemento

const el = document.querySelector(".card");

// Metodo moderno (preferito)
el.remove();

// Metodo classico — tramite il padre
el.parentElement.removeChild(el);

// Rimuovere tutti i figli di un elemento
const lista = document.querySelector("ul");

// Metodo 1 — innerHTML (svuota l'elemento)
lista.innerHTML = "";

// Metodo 2 — loop (più controllato)
while (lista.firstChild) {
  lista.removeChild(lista.firstChild);
}

// Metodo 3 — moderno
lista.replaceChildren();  // svuota senza innerHTML

Clonare un Elemento

const originale = document.querySelector(".card");

// cloneNode(true) = copia profonda (figli inclusi)
const copia = originale.cloneNode(true);
copia.id = "card-copia";  // ⚠️ id deve essere unico
document.body.appendChild(copia);

// cloneNode(false) = solo il tag, senza figli
const guscio = originale.cloneNode(false);
⚠️ Dopo cloneNode(true) i figli clonati mantengono gli stessi id dell'originale: ricordati di cambiarli, gli id devono essere unici nella pagina.
⚠️ Svuotare con innerHTML = "" è pratico ma rimuove anche gli event listener aggiunti ai figli. Usa replaceChildren() o il loop con removeChild per un controllo maggiore.

Navigare l'Albero DOM

05 · 10/12

Proprietà di Navigazione

const li = document.querySelector("li.attivo");

// ↑ Padre
li.parentElement;          // il <ul> o <ol>
li.parentElement.parentElement; // nonno

// ← Fratelli →
li.previousElementSibling; // li precedente
li.nextElementSibling;      // li successivo

// ↓ Figli
li.parentElement.children;         // tutti i figli
li.parentElement.firstElementChild; // primo
li.parentElement.lastElementChild;  // ultimo
li.parentElement.childElementCount; // quanti

// Cercare il più vicino antenato che fa match
li.closest(".container"); // risale fino a trovarlo
li.closest("form");        // o null
ProprietàDirezioneTipo restituito
parentElement↑ suElement | null
children↓ giùHTMLCollection
firstElementChild↓ giùElement | null
lastElementChild↓ giùElement | null
previousElementSibling← fratelloElement | null
nextElementSibling→ fratelloElement | null
closest()↑ antenatoElement | null
💡 closest() è molto utile nella gestione degli eventi: se clicchi su un <span> dentro un <li>, puoi recuperare il <li> con span.closest("li") senza sapere quanti livelli ci sono in mezzo.

Esempio Completo — Lista Dinamica

06 · 11/12

HTML di partenza

<input id="campo" type="text" placeholder="Aggiungi...">
<button id="aggiungi">+</button>
<ul id="lista"></ul>
const campo    = document.getElementById("campo");
const btnAgg   = document.getElementById("aggiungi");
const lista    = document.getElementById("lista");

function aggiungiVoce() {
  const testo = campo.value.trim();
  if (!testo) return;

  const li  = document.createElement("li");
  const btn = document.createElement("button");

  li.textContent   = testo;     // testo sicuro
  btn.textContent  = "✕";
  btn.className    = "elimina";
  btn.addEventListener("click", () => li.remove());

  li.appendChild(btn);
  lista.appendChild(li);

  campo.value = "";           // svuota il campo
  campo.focus();              // rimette il cursore
}
// Aggiungi al click del bottone
btnAgg.addEventListener("click", aggiungiVoce);

// Aggiungi anche premendo Invio
campo.addEventListener("keydown", e => {
  if (e.key === "Enter") aggiungiVoce();
});

// Modificare il testo di una voce al doppio click
lista.addEventListener("dblclick", e => {
  const li = e.target.closest("li");
  if (!li) return;
  const nuovo = prompt("Modifica:", li.firstChild.textContent);
  if (nuovo !== null) li.firstChild.textContent = nuovo;
});
✅ Event delegation: invece di aggiungere un listener su ogni <li>, ne aggiungiamo uno solo sul <ul> padre. Gli eventi "risalgono" (bubbling) e closest() identifica l'elemento corretto.
💡 Nota che li.textContent = testo non crea vulnerabilità XSS, mentre li.innerHTML = testo sì — specialmente se testo proviene dall'input dell'utente.
